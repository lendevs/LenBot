# 插件工具回放场景

`cases.json` 是一组固定时间与消息来源的虚构群聊场景，用于核对提示词或工具定义修改前后聊天模型的工具选择、参数构造及对返回结果的解读。

## 使用方法

在隔离测试实例中安装四个官方业务插件，将 `cases.json` 中的虚构消息作为会话输入，逐项对照 `expected_tools` 与 `expect`：

- 场景基准时间固定为 `2026-10-06 18:00`（`Asia/Shanghai`），群日报原文使用虚构记录。
- 预期的时间区间写在各用例内；用例中的今天下午约定为从 `12:00` 开始，其余时间表达由模型按语境判断。

## 覆盖范围

- 账号读取或写入开关未开启时的可用性过滤
- 多人交叉发言与主人后置发言时的 `source_message_id` 归属
- 真实动态 ID 在列表查询与详情读取工具之间的传递
- 后台异步生成并由插件自行发送的回执语义
- 插件共享工具指南（`[model] instructions`）的加载与撤下

回放使用 `simulated` 发送和隔离配置，不操作外部真实账号。

## 自动化协议测试

- 宿主 `tests/test_plugin_tool_contract.py` 验证工具定义投影、`source_message_id` 权限校验和共享指南生命周期。
- 群聊总结插件 `tests/test_incremental.py` 使用 `PluginTest` 固定时钟与本机模拟模型服务验证时间窗口与缓存。
- 哔哩哔哩插件 `tests/test_content.py` 验证 `unavailable_tools` 过滤以及非主人来源请求在联网前的拦截。
