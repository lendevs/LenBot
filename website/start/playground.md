# 对话测试

对话测试在隔离实例中模拟一个群聊。Bot 使用所选群的角色和模型运行回合，回复只显示在面板中，不发送到 QQ。

<CardImage name="playground" alt="对话测试页：依次以老周、橘子、小满的身份发言，小然在左侧回复，右侧列出每个回合" />

## 开始一次测试

1. 打开面板左侧的**对话测试**，点击**开始新测试**。
2. **设置来源**选择**使用群聊设置**并选中一个群，或选择**使用角色试聊**并选中一个角色。
3. **初始上下文**选择**从空白开始**，或复制群内最近 20、50、100 条消息。
4. **发言时机**与**参与频率**默认沿用所选群的设置，可改为另一种方式对比效果，只影响这次测试。
5. 点击**开始测试**。

测试信息行标出这次使用的参与方式，**参与方式设置**跳到该群的设置页。

群聊页右上角 **…** 菜单中的**使用本群设置试聊**也会打开对话测试。**测试记录**列出进行中和已结束的测试，结束后聊天记录保留。

## 群友与发言身份

输入框上方是发言身份。点击群友切换身份，点击 **+** 添加群友：

| 字段 | 取值 |
|---|---|
| 昵称 | 群内显示的名字 |
| 账号 | 自动分配 |
| 身份 | 成员、管理员或群主 |

群友列表按群保存在当前浏览器中，下次测试同一个群时沿用。

**@ 群友**在消息中插入 @，消息上的**回复**引用这条消息。唤醒规则与所选群相同，每条群友消息旁的闪电或月亮标出是否唤醒 Bot，点击查看原因、参与分和插话门槛，与群聊页现场一致。

## 多人情境

聊天窗口右上角的**多人情境**按顺序以前两位群友的身份发出一组消息：

| 情境 | 消息 |
|---|---|
| 有人呼叫 Bot | 群友 @ Bot 提问 |
| 群里的开放问题 | 两位群友先后提出一个没有指定对象的问题 |
| 别人之间在聊 | 两位群友互相 @ 和接话 |
| Bot 发言后的续接 | 群友 @ Bot 提问，Bot 回复后不带 @ 继续追问 |

同一组情境分别在只回应呼叫和参与讨论两种方式下运行，可以对比 Bot 何时接话。

## 查看回合

右侧**回合**列表与群聊页现场的回合卡片一致：唤醒原因、召回的记忆、每一步的想法、工具调用和发出的消息。点击 Bot 的消息可跳到它所在的回合。

## 隔离范围

| 项目 | 对话测试中 |
|---|---|
| 发送 | 模拟发送，不连接 QQ |
| 长期记忆 | 独立的空白本地记忆 |
| 群资料 | 开始测试时复制所选群的资料文件，之后群资料的改动不影响进行中的测试 |
| 工具 | 依赖聊天平台的工具不加载，其余按角色许可 |
| 插件、后台任务、学习、主动发起话题、语音转写 | 不加载 |
| 模型与用量 | 使用所选群绑定的模型，token 计入用量统计 |

## 接入群聊

确认效果后：

1. 打开**总览**，把顶部状态卡的**发送方式**从**模拟发送**切换为**发送到 QQ**，立即生效。
2. 在真实群内 @ Bot，确认消息送达。
3. 在**群聊**页点击 **+** 接入更多群，群聊开关可暂停或恢复单个群。
4. 接入时选择**发言时机**：**只在被 `@`、回复或私聊时**，或**同时参与群内讨论**；参与讨论时再选**参与频率**（少、适中、多）。之后可在**群聊 → 设置 → 参与方式**中修改。

唤醒方式和发言上限见[在群里聊天](../use/chatting)。
