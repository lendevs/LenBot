# 首次配置

实例目录中不存在 `lenbot.config.json` 时，`len-bot` 会启动首次配置向导并在终端打印带一次性令牌的本机链接；在本机桌面环境启动时会自动唤起默认浏览器。

```text
尚无根配置。请打开 http://127.0.0.1:52811/#token=...
```

向导仅监听 `127.0.0.1`，端口每次启动随机分配，`token` 仅对本次进程有效。Docker 部署的向导固定使用容器端口 `11307`，见 [Docker 部署](./docker#_3-首次配置)。已填写的非敏感草稿暂存在当前浏览器标签页的会话存储中，刷新页面不会丢失；密码与 API Key 不落入浏览器存储，刷新后需重新输入并重新测试 QQ 连接。

首次保存后向导不再出现，后续所有设置均在管理面板中修改。无浏览器环境下也可通过 JSON 文件完成非交互初始化，见[部署包与容器安装](https://github.com/lendevs/LenBot/blob/master/deploy/current/installation.md#无交互初始化)。

## 1. 管理员账号

设置面板登录用户名与密码（至少 8 位，不能全为空白）。每个实例设有一个管理员账号。

**面板端口**默认为 `8088`，默认仅监听本机回环地址 `127.0.0.1`。远程服务器访问方式见本页末节[从其他机器打开面板](#从其他机器打开面板)。

## 2. 连接 QQ

支持两种 OneBot v11 WebSocket 连接方向：

- **LenBot 连接 OneBot（正向 WebSocket）**：填写 **OneBot 地址**，宿主机直接运行时默认 `ws://127.0.0.1:3001`，在 Docker 容器中运行时默认 `ws://host.docker.internal:3001`。
- **OneBot 连接 LenBot（反向 WebSocket）**：填写 LenBot 的**监听地址**与**监听端口**，并在 OneBot 客户端侧把反向 WebSocket 地址指向该端口。

OneBot 客户端一侧的配置要求见[接入 QQ](../connect/onebot)。

**访问令牌**需与 OneBot 客户端中的设置完全一致，未设置时留空；反向 WebSocket 监听非回环地址时必须设置访问令牌。

点击**测试连接**，LenBot 会握手并读取当前登录的 Bot QQ 号，显示 `已连接，Bot 账号 …` 后方可进入下一步。

**发送方式**首次配置建议选择**模拟发送**：Bot 正常接收群消息并运行回合，但回复仅展示在面板中。验证效果后可在面板**总览**随时一键切换为**发送到 QQ**。

## 3. 主人与时区

填写**主人 QQ**（纯数字账号）。主人拥有最高管理权限，可使用全部斜杠命令并在群内让 Bot 修改设置。更多主人或管理员账号可在进入面板后添加。

**时区**默认为 `Asia/Shanghai`，定时提醒、每日安静时段、主动发起话题窗口与每日用量统计均按此时区计算。

## 4. 聊天模型

本步配置主聊天模型（`mind` 用途）。看图、记忆摘要、插件生成与后台任务未单独指定模型时均默认复用该聊天模型，详见[模型与用量](../connect/models#模型用途)。

服务商预设提供 **DeepSeek**、**OpenAI 兼容**和 **Anthropic 兼容**三项：

- **DeepSeek**：预填官方接口地址、默认模型与思考参数，填入 API Key 即可测试。
- **OpenAI 兼容**：适用于各类提供 `/v1/chat/completions` 接口的服务商，填入接口地址、密钥和模型名。
- **Anthropic 兼容**：预填官方地址、默认开启图片输入并将思考强度设为 `high`。

填写接口地址与密钥后，可读取服务商的模型列表搜索选择，也可手动输入模型 ID，再点击**测试模型**验证连通。

**首轮请求使用低档思考（推荐）**：开启后，每轮收到消息后的第一次模型请求使用 `low` 档思考强度以降低首句延迟，调用工具查证后的续接步骤恢复主思考强度。DeepSeek 与 Anthropic 兼容预设默认开启，后续可在**模型 → 用途 → 聊天**中修改。

同一页还可选择网页**搜索服务**和**读取方式**：

| 搜索服务 | 密钥与连接 |
|---|---|
| DeepSeek | 聊天服务商为 DeepSeek 官方地址（`api.deepseek.com`）时可直接复用，否则单独填写 DeepSeek 密钥 |
| Tavily、Brave Search、博查 | 单独填写对应服务的 API Key |
| Yahoo、Bing RSS | 无需密钥，也可选择**关闭搜索** |

| 读取方式 | 密钥与连接 |
|---|---|
| 本机直接读取 | 默认项，无需密钥，由 LenBot 直接抓取网页并提取正文 |
| DeepSeek | 复用 DeepSeek 搜索连接或官方聊天连接 |
| Tavily | 与 Tavily 搜索共用同一连接 |
| Jina Reader | 填写 Jina API Key，也可选择**关闭读取网页** |

展开底部的**更多设置**可调整网络代理、上下文长度、**输入压缩阈值**、最长输出、思考参数、**聊天模型支持图片**、**每轮最多步数**（默认 `16`），以及可选的**向量模型（推荐）**：

- 配置向量模型后，长期记忆与资料文件支持语义与全文混合检索；选择**不使用**时仅使用全文检索。
- DeepSeek 官方接口不提供向量端点，配置向量模型时请选择**使用其他服务商**（例如本地 Ollama 或其他兼容 `openai-embeddings` 的服务商），也可留到进入面板后在**模型 → 向量模型**中开启。

## 5. 角色和第一个群

**角色**默认选择**小然（默认角色）**，保存时自动将内置的小然角色包复制到实例的 `personas/companion/`。选择**自定义角色**时需填写**角色名字**与**人物设定**，**说话方式**和**底线**选填；展开**更多设置**可指定**角色文件夹名**（仅限小写英文字母、数字和连字符 `-`）。

**首个场景**可选择**群聊**并填写群号，或选择**私聊**并填写对方 QQ 号。群聊另选**发言时机**：默认**只在被 `@`、回复或私聊时**，也可选**同时参与群内讨论**并选择**参与频率**（少、适中、多）。

展开**更多设置**可勾选需要一并下载安装的**官方插件**。勾选的插件在保存配置时从官方仓库拉取安装，安装后默认处于停用状态，进入面板的**插件**页填写参数并启用后生效。

## 保存与进入面板

点击**保存并进入面板**（或**跳过插件，直接保存**）后，宿主写入 `lenbot.config.json` 并正式启动，页面在面板就绪后自动跳转至登录页。

若等待超时后页面显示**配置已保存**，说明配置文件已成功写入磁盘但浏览器未能连上新面板端口：

- 使用 SSH 端口转发或反向代理时，面板实际端口（默认 `8088`）与刚才向导的随机端口不同，请按新端口转发后打开面板地址。
- 本机直连仍无法访问时，查看启动终端输出（常见原因为 `8088` 端口已被占用）。排除端口冲突后重新运行 `len-bot` 即可直接加载已保存的配置，无需重走配置向导。

## 从其他机器打开面板

面板默认仅绑定 `127.0.0.1:8088`。在远程服务器上运行时，推荐通过 SSH 本地端口转发访问：

```sh
ssh -L 8088:127.0.0.1:8088 你的服务器
```

连接保持期间，在本机浏览器打开 `http://127.0.0.1:8088` 即可登录。

需要长期通过域名从公网访问时，请在面板前额外部署 HTTPS 反向代理：

1. 在**系统 → 设置 → 面板账号**中开启**只允许通过 HTTPS 登录**（`panel.secure_cookies: true`）。
2. 反向代理保留原始 `Host` 头，并传递 `X-Forwarded-For` 与 `X-Forwarded-Proto`，同时支持 WebSocket 升级（用于面板实时推送流）。
3. 反向代理与 LenBot 不在同一台机器上时，停止 LenBot 后将代理服务器 IP 写入 `lenbot.config.json` 的 `panel.trusted_proxies`，使登录限流按真实客户端 IP 计数。
