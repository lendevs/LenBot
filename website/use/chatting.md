# 在群里聊天

## 唤醒方式

Bot 仅在被唤醒时发起聊天模型请求；未被唤醒的群消息只写入本地记录作为后续上下文。被唤醒后，是否开口以及回复哪条消息均由聊天模型自行决定。

| 唤醒方式 | 触发条件 |
|---|---|
| 被 `@` 或回复 | 消息 `@` 了 Bot、引用回复了 Bot 的消息，或来自私聊 |
| 点名 | 消息文本中出现当前角色的名字、角色别名或本群附加称呼 |
| 持续关注 | 命中了 Bot 先前通过 `attention` 工具登记的待跟进事项 |
| 对话继续 | Bot 回复某人后这个人的下一条消息，或 Bot 主动插话后任何人的下一条消息 |
| 群内讨论 / 随机唤醒 | 开启**同时参与群内讨论**后，距 Bot 上次发言超过插话间隔时群里出现可以接的话，或命中低概率随机唤醒 |
| 提醒 / 任务 / 插件 | 定时提醒到点、后台任务完成或提问、插件主动推送场景事件 |
| 主动发起话题 | 开启后，群内静默超过设定时长（默认 3 小时）且处于每日允许时段（默认 `10:00`–`22:00`）时触发，每天最多一次 |

首次配置和接入群聊时选择**参与频率**，分活跃、适中、安静三档，与首页群聊列表的唤醒档位相同，默认适中；接入群聊时还可以选择以**插件**模式接入。在**群聊 → 设置 → 参与方式**中可改为**只在被 `@`、回复或私聊时**。档位设定插话间隔和发言节奏：

| 档位 | 发言后到插话的最短间隔 | 最多连续发言条数 | 之后每条发言的间隔 |
|---|---|---|---|
| 活跃 | 10 分钟 | 3 | 2 分钟 |
| 适中 | 30 分钟 | 3 | 3 分钟 |
| 安静 | 90 分钟 | 2 | 5 分钟 |

插话间隔从 Bot 上次发言起算。Bot 主动插话后没人接话，下一次插话的间隔翻倍，最长为最短间隔的 4 倍；有人接 Bot 的话、`@` 或点名 Bot 后回到最短间隔。发言节奏对所有聊天唤醒生效，被 `@` 也一样：连续发完上限条数后，下一条按间隔发出。提醒和后台任务结果不受发言节奏限制。

之后可在**群聊 → 设置 → 参与方式**或首页修改；在**等待与插话参数**中改动其中任一数值后，档位显示为**自定义**。

开启**观察群友对 Bot 发言的反应**（位于**群聊 → 学习 → 学习设置**）后，宿主会根据近期主动插话后的群友反馈调整插话间隔：近期插话常被无视或引起反感时，间隔按系数延长，最多延长到原来的 2 倍；群友顺着话题继续讨论或表示认同时，间隔按系数缩短，最多缩短到原来的 0.8 倍。同样多的反馈，延长比缩短快。反馈权重随时间衰减，超过 3 天的记录不再计入。被 `@`、被回复、点名和对话继续不受此系数影响。

### 对话继续

Bot 每次发言后等一次接话：回复了谁，就等这个人的下一条消息；主动插话时没有回复具体的人，就等任何人的下一条消息。这条消息在**回复后等对方接话的时长**（默认 120 秒）内到达时，不用再 `@` 就按**对话继续**唤醒，每次发言只唤醒一次。其他群友的消息仍需 `@`、回复或点名 Bot。填 `0` 时关闭对话继续。

回合里聊天模型能看到 Bot 最近 10 分钟的发言条数和群里其他人的消息条数，说得多时，起哄和单纯的情绪用一个表情回应。

## 私聊

主人（**系统 → 设置 → 权限**中的主人账号）给 Bot 发私聊时，Bot 直接对话：第一条私聊会自动接入这个私聊，沿用同一平台第一个群的角色，之后在**群聊**页列出，可以像群一样修改设置。关闭**主人私聊时直接对话**后，主人的私聊不再自动接入，已接入的私聊保持不变。

需要接入其他人的私聊时，在**群聊**页点击 **+**，手动输入私聊账号。

### 持续关注与对话收尾

**群聊 → 设置 → 持续关注与对话收尾**中有两个开关，持续关注默认开启，对话收尾默认关闭：

- **持续关注**：群友说等下发日志、晚点再说时，Bot 用 `attention` 工具登记要等什么（等某人发言、等对某条消息的回复、等某个话题再出现或到时检查）。之后相关消息出现时，即使中间隔着别的话题，Bot 也会被叫醒跟进；处理完或对方表示不用了，关注事项随即结束，到期也自动结束。需要角色允许 `attention` 工具，未允许时该开关下方会提示并链接到角色页。Bot 也会自己登记想接着聊的人或话题；登记过的事项是它主动开口的主要依据，没有登记时才按插话间隔偶尔看一眼群。主动接话时，Bot 会看到那段话离现在多久、之后群里是否已经在聊别的，默认不去接已经过去的话题。
- **对话收尾**：Bot 在一轮结束时可以标记对话已收尾（暂停对话继续和插话）或只继续等指定的人接话，状态在设定的分钟数后失效。

当前生效的关注事项和收尾状态显示在**群聊 → 现场**的时间线上方，每个关注事项列出触发条件和到期时间，点击 **×** 取消。被 `@`、回复和点名不受这两项影响。**高级设置**中的运行模式和数量上限用于实验，一般保持默认。

## 连发合批与回复方式

### 连发消息合批

群友习惯把一句话拆成几条短消息或先发图再补文字。Bot 被唤醒后不会立刻请求模型，而是先等待一小段空闲时间将连续到达的消息合并进同一回合：

- **已发言人续发顺延**：本批等待期间已经发过言的群友再次发送消息时，空闲计时顺延（即使中间夹着其他群友插话也同样顺延）；本批首次出现的新发言人发消息不重新计时。
- **纯图片延长等待**：若当前最后一条消息仅包含图片，且发图人本批已发过言（或该图片本身就是唤醒消息），空闲等待时间加倍，留出补充说明文字的时间。
- **总时长封顶**：每种唤醒渠道均设有最长等待秒数（例如**被叫到后的最长等待秒数**默认为 4 秒），达到上限后立即进入回合。进入回合后，若模型判断对方仍在输入，也可调用 `wait` 工具再等待数秒读取新消息。

### 回复形式

聊天模型在同一回合内可组合使用这几种方式：

- **文字发言（`say`）**：发送一条或多条消息，支持引用目标消息或 `@` 指定群友。单条文本超过字数上限（默认 300 字）时在换行或句末自动分段，并按配置的打字速度控制分条间隔。
- **发送表情（`react`）**：单独发送角色表情或本群收集的表情图片，或在调用 `say` 时将文字与表情合成为同一条消息发出。同一情绪下有多张相近候选、只看文字描述难以区分画面细节时，支持看图的聊天模型可先预览最多 9 张带编号的候选缩略拼图，再按编号发送；发送副本最长边自动缩放至 320 像素并保留动图帧，角色包原图不变。
- **贴表情回应（`message_reaction`）**：调用 QQ 群消息贴表情接口，为某条群消息贴一个简短表情回应而不发出新气泡。
- **旁听不发言**：不调用任何对外表达工具（或显式结束回合），继续保持安静。

同一回合内若连续两次发送出现 `发送失败`、`发送状态未知` 或部分送达，该回合立即以 `发送失败` 状态终止，不再继续后续发送步骤。

## 收集群内表情

在**群聊 → 学习 → 学习设置**中开启**收集群内表情**后，宿主会自动跳过平台标记为普通照片或截图的图片，仅使用看图模型为表情包生成画面描述、图中文字、情绪和适用标签。

同一群内重复出现的相同图片复用已有标注与审核状态。新识别的表情进入**待审核**列表，按群内发送频次优先排列并展示发送次数与人数；在**群聊 → 学习 → 表情**中点击**采用**后即可供 Bot 在该群发送。各群收集的表情库相互独立。

## 首轮请求低档思考

开启**首轮请求使用低档思考（推荐）**（位于**模型 → 用途 → 聊天**）后，回合第一步请求使用 `low` 档思考强度快速给出直接回复或工具调用；若第一步调用了查询工具，同一回合后续读取工具结果的请求自动恢复主思考强度。

## 安静时段与临时安静

- **每日安静时段**：在**群聊 → 设置 → 每日安静时段**中设定起止时间（支持跨零点，例如 `23:00` 至 `08:00`）。安静时段内 Bot 不主动插话或发起话题；期间被 `@` 时的行为可选**照常回复**、**回复固定内容**或**安静时段结束后回复**。
- **临时安静**：在群聊工作台右上角 **…** 菜单点击**临时安静**，或由有权限的成员在群内发送 `/quiet <分钟>`（最长 7 天），也可由模型应群友要求调用 `scene_control` 工具进入临时安静。
- **插件安静**：声明 `quiet` 权限的插件可以让本群临时安静并按需续期，例如 B 站插件在订阅的直播间直播期间。主人设置的更长的临时安静保持不变，插件解除时只解除自己设置的安静。

## 每小时发言上限

LenBot 按滑动 60 分钟窗口统计每个群的发言次数，全局默认上限为每群每小时 60 条（在**系统 → 设置 → 群聊**中修改）；单群可在**群聊 → 设置 → 每小时发言上限**中选择**跟随全局**、**自定义**或**不限**。私聊不设每小时发言上限。

- 每次成功送达的 `say`（无论自动拆分为几段或是否附带表情）、`react` 单独发表情，以及 `/help`、`/id` 命令回复，各计 1 条。
- `message_reaction`（给消息贴表情）、管理员维护命令回复、每日安静时段的固定提示语，以及插件自行发出的消息均不计入上限。

常规额度用尽后，Bot 停止主动插话和发起话题；被 `@`、被回复、到点提醒和后台任务结果可使用额外余量（**用完后被 `@` 时的额外条数**，默认 5 条）。余量也耗尽后该群暂停发言，待滑动窗口内最早的发言滑出 60 分钟后自动恢复，期间积累的未读消息保留至恢复后处理。

可在**系统 → 设置 → 群聊**中开启**全部用完后被 `@` 时回复固定内容**（每次限流周期最多提示一次）。达到上限的群会出现在**总览**的待处理事项中，也可在群设置页点击**本小时临时放开**立即清零当前窗口计数。

## 聊天模式与唤醒档位

- **开启／关闭**：首页群列表和群聊页顶栏的开关。关闭后该群不唤醒模型，插件的命令、通知、定时任务和推送都不响应，群内命令也不响应，消息照常记录；只能在面板中重新开启，开启后回到关闭前的聊天／插件模式。
- **聊天／插件**：首页群列表的方形按钮和群聊页顶栏显示当前模式，点击切换。聊天模式允许模型参与；插件模式继续记录消息、响应插件和命令。重新开启聊天后从新消息开始处理。
- **全部暂停 / 全部恢复**：位于**总览**顶部状态卡，一键暂停或恢复所有已接入群聊。
- **唤醒档位**：在首页群列表选择**活跃／适中／安静**，保存即生效。各档的插话间隔和发言节奏见[唤醒方式](#唤醒方式)，详细参数可在群设置中调整。
- **每日 token 上限**：按全实例合计或按单群限制每日模型 token 消耗，详见[模型与用量](../connect/models#用量与上限)。
