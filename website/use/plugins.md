# 插件管理

插件通过 Python 扩展斜杠命令、消息匹配规则、定时播报、聊天模型工具、后台任务技能，或按群接管长期记忆与回想压缩。LenBot 核心不内置具体业务功能，官方业务插件按需独立安装与升级。

## 官方插件目录

内置插件目录（`plugin_catalog.json`）收录四个官方插件，可在首次配置向导或面板**插件 → 发现插件**中直接安装：

| 插件 | 主要功能 |
|---|---|
| [群聊总结与群工作](https://github.com/lendevs/lenbot-plugin-group-digest)（`group_digest`） | `/群日报` 生成图文总结卡片并支持每日定时播报，`/群总结` 生成文字摘要，`/群工作` 委派后台长任务；同时提供对应的聊天模型工具 |
| [GSUID Core 桥接](https://github.com/lendevs/lenbot-plugin-gscore-adapter)（`gscore_adapter`） | `/gs` 将指令桥接至独立运行的 GSUID Core 服务并由宿主发送返回图文，提供 `/gs连接` 重连指令与连接状态查询工具 |
| [A-SOUL 日程与动态](https://github.com/lendevs/lenbot-plugin-asoul)（`asoul`） | 读取日历通过 `/日程` 发送日程卡片并在开播前推送场景事件，提供成员动态、往年今日与二创检索及卡片发送工具 |
| [哔哩哔哩](https://github.com/lendevs/lenbot-plugin-bilibili)（`bilibili`） | 公开视频、分 P、搜索与评论查询，订阅直播间开播／下播与关注 UP 主动态推送，以及经主人明确授权的账号读取与点赞收藏操作 |

官方目录默认使用随当前宿主版本测试固定的提交；也可在**发现插件 → 目录来源**中填入自定义远程目录地址。

## 安装与按群启用

在**插件 → 发现插件**（或**已安装 → 安装插件**）中支持三种安装来源：

- **从插件目录挑选**：一键拉取内置或远程目录中的插件。
- **从 Git 仓库安装**：填写 HTTP(S) 或 `ssh://` 仓库地址，可选填标签、分支或提交哈希（主机需已安装 `git`）。
- **导入 ZIP 文件**：上传打包好的插件发行归档（支持离线环境）。

安装采用安全的两阶段候选机制，准备期间不影响正在运行的旧版本：

1. **准备候选版本**：下载或解压源码至 `plugins/.candidates/<名称>`，校验 `plugin.toml` 清单中的接口代次、宿主版本范围、Python 版本和操作系统平台。
2. **填写参数并应用**：在插件详情的**设置**页签补全必填参数后点击**应用**（新插件点击**保存并启用**）。若 Python 依赖未变化且插件声明 `reload = "plugin"`，宿主当场热加载该插件；若需要安装新 Python 依赖、切换进程隔离模式或插件声明 `reload = "host"`，则登记为待应用状态并在下次点击面板**重启**时自动安装依赖并切换。

新安装的插件默认未分配给任何群。启用插件后，在插件详情的**使用的群**页签（或**群聊 → 设置 → 本群启用的插件**）中勾选目标群即可立即生效，仅重载该插件，不中断其他群聊。

插件详情页共设六个页签：**设置**、**使用的群**、**工具**、**技能**、**日志与错误**、**版本**。

## 更新、自动恢复与手动回退

- **更新版本**：在**版本**页签点击**更新或选择版本**准备新候选版本。候选配置独立暂存，点击取消候选不会改动当前线上运行的参数。
- **启动失败自动回退**：应用新版本时，旧版源码自动移入 `plugins/.previous/<名称>`。若新版本在导入、`start()` 启动或 `migrate_data()` 数据迁移阶段抛出异常或超时，宿主自动切回上一版源码；若新版本已触发数据目录迁移，宿主会一并从 `plugins/.data/.backups/` 还原迁移前的数据备份。
- **手动回退**：运行期间可在**版本**页签点击**回退到上一版本**，一键恢复上一版的源码和参数配置（若新版本已提升过 `data_version`，旧版插件会拒绝读取更高版本数据，需停机配合 `.backups/` 中的旧数据备份一并还原）。

## 权限控制与进程隔离

- **最小权限声明**：插件在 `plugin.toml` 的 `permissions` 中显式列出所需的宿主能力（如 `send`、`events`、`history`、`memory`、`generate`、`delegate`、`network`、`schedule`），面板会在详情页展示权限清单；越权调用会被宿主直接拦截并记为 `PermissionError`。未声明 `permissions` 字段的旧清单默认保留完整宿主能力并标注为**未声明权限**。
- **进程隔离**：插件可运行在**与主程序同进程**（`inline`，支持全部入口与模型工具）或**独立进程**（`process`，崩溃仅影响该插件子进程，点击**重载**即可拉起新进程）。

## 停用、卸载与数据清理

- **停用**：停止命令、工具、定时任务与后台循环，保留全部配置参数、启用群列表和数据文件。
- **卸载**：停止插件并移除源码目录与 `lenbot.config.json` 中的启用配置，但默认保留 `plugins/.data/<名称>` 下的业务数据。
- **删除数据**：卸载或停用后，可在**已安装**页底部的**已卸载插件的数据**中单独执行不可逆的数据目录删除。

自行开发插件的完整步骤见[写插件](../develop/plugins)。
