# 后台任务

编写长篇报告、批量处理数据、抓取渲染网页等耗时数分钟至数十分钟的工作，可由聊天模型通过 `delegate` 工具委托给后台任务。每个任务在独立的无直连网络 Docker 容器中由编程助手 Pi 执行；任务运行期间，群内日常聊天照常进行。

后台任务默认关闭，日常聊天、查资料和记忆功能不依赖 Docker。

## 启用步骤

宿主机需安装并启动 Docker Engine（Windows 可使用 Docker Desktop + WSL2）。

1. **构建任务容器镜像**：在仓库根目录执行：
   ```sh
   docker build -t lenbot-worker:local -f docker/next-worker/Dockerfile .
   ```
2. **开启全局后台任务**：进入面板**能力 → 后台任务**，打开**启用后台任务**。面板会自动按当前机器环境预填默认路径，核对以下项目并选择**任务模型是否支持推理**后保存重启：
   - **任务镜像**：填写 `lenbot-worker:local`（使用官方发行镜像时保持对应镜像标签）。
   - **Docker 程序路径**与 **Docker 地址**（例如 `unix:///var/run/docker.sock`）。
   - **容器用户 UID** 与 **GID**（需对下述宿主机任务目录具备读写权限）。
   - **任务工作目录**（`task-workspaces`）、**任务运行目录**（`task-runtime`）、**任务交付目录**（`deliveries`）及可选的**技能目录**：均填写宿主机绝对路径，且三个任务目录互不嵌套、Docker 守护进程可挂载访问。
3. **可选绑定专用模型**：任务默认跟随聊天模型；如需指定独立编程模型，可在**模型 → 用途**中配置**后台任务**（`worker`）。
4. **按群开启与授权**：在**群聊 → 设置 → 提醒与任务**中开启**允许委托任务**并按需调整并发与流量配额；在**群聊 → 设置 → 权限**的权限矩阵中勾选允许**委托任务**的成员身份。
5. **检查角色许可**：确保该群角色在**角色 → 工具与技能**中允许 `delegate`、`task`、`send_file` 与 `tool_search` 工具，以及任务所需的技能。

任务容器本身处于无网卡隔离状态（`--network none`）；容器内的模型请求、公网 HTTP 访问、浏览器操作与本群只读数据工具（记忆、资料、历史聊天查询）均经由宿主进程代理并计入流量与额度上限，API Key 始终留在宿主进程内。

## 联网方式

在**能力 → 后台任务 → 任务能力**中选择任务的**联网方式**：

| 联网方式 | 任务能连接的地址 |
|---|---|
| **不联网**（默认） | 只能经宿主调用模型 |
| **按域名放行** | 只连**可连接的域名**中的域名；`*.example.com` 匹配它的所有子域名，不含 `example.com` 本身；不能直接连 IP 地址。**加入软件包源**一次填入 `pypi.org`、`files.pythonhosted.org`、`registry.npmjs.org` |
| **公网** | 公网地址；内网、环回和保留地址始终不可连接 |

三种方式都受**更多限制**中的流量、速度和连接数上限约束，每个任务的上传量另有上限（默认 20 MB）。被拒绝的连接及原因记入任务事件，任务可用 `network_status` 读取。浏览器 `lenbot-browser` 跟随联网方式：不联网时不可用，按域名放行时只能打开名单内的网站。本地 HTML 渲染 `lenbot-render` 离线运行，不受联网方式影响。

## 磁盘空间

- 每个任务的工作区与运行目录合计不超过**每个任务的目录大小上限**（默认 2 GB），超过时任务停止并记录原因。
- 任务目录所在磁盘剩余空间低于 5 GB 时不接收新任务，已排队的任务等空间恢复后再开始；低于 2 GB 时停止运行中的任务。
- 任务结束 14 天后自动删除工作区与运行目录，交付文件和任务记录保留。
- 以上数值都在**更多限制**中调整。

## 日常使用与空间管理

在**群聊 → 任务**页签下可通过四个视图管理单群工作流：

- **资料输入**：在**任务空间与文件**视图中可上传**本群共享资料**，也可从历史任务的工作区或交付副本中挑选文件（单个新建任务最多挂载 16 份只读输入快照）。
- **实时预览、提问与续接**：任务执行期间可在面板查看实时输出流与每一步操作事件。任务需要发起人确认方案或补充信息时会进入**等待回答**状态（等待期间不占用并发运行槽位）；任务完成后，只要工作区尚未释放，群友或运营者均可追加要求按原会话和原目录**继续任务**。
- **网页渲染**：任务镜像内置无头渲染工具 `lenbot-render`，可将生成的 HTML 页面直接导出为排版好的 PDF 或高清长截图。
- **任务编写的技能**：任务在执行过程中编写的可复用技能可在任务详情的**更多 → 任务编写的技能**中审阅，并一键采纳移入**本群**或**共享**技能库（之后可在**能力 → 技能**中管理）。
- **分级清理空间**：在**任务空间与文件**中可按时间筛选任务并计算磁盘用量。**清理临时文件**仅移除控制管道、运行日志和浏览器临时目录，保留工作区与会话供后续续接；**释放环境**彻底删除工作区和运行目录（不可再续接），已登记的交付副本、本群共享资料和数据库任务记录仍然保留。

## 发送到 QQ

任务在容器内产出文件后，**登记为交付**与**发送到 QQ** 是两个独立步骤，可在面板中预览下载，也可由聊天模型调用 `send_file` 或在面板点击发送将交付文件上传至 QQ 群文件。

由于 OneBot 协议端通过本地路径读取待上传文件，当 OneBot 与 LenBot 不共享同一根文件系统（例如分处两个容器）时，需完成两步映射：

1. 将宿主的**任务交付目录**以只读方式挂载进 OneBot 容器。
2. 在**系统 → 设置 → 连接 → 更多设置**中，将 **OneBot 可见的文件目录**（`onebot.upload_visible_root`）填写为 OneBot 容器内部看到的那条挂载绝对路径。

## 重启与镜像更新

重启 LenBot 会中断当时正在运行的任务容器并将其状态记为中断，其工作区文件与任务会话完整保留，重启后可直接续接；排队中的任务保留原队列顺序。

更新了 `docker/next-worker/` 源码后，重新执行 `docker build` 构建新标签镜像，并在面板**能力 → 后台任务**中更新**任务镜像**名称后保存重启。
