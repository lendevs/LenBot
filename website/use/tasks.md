# 后台任务

编写长篇报告、批量处理数据、抓取渲染网页等耗时数分钟至数十分钟的工作，可由聊天模型通过 `delegate` 工具委托给后台任务。每个任务在隔离环境中由编程助手 Pi 执行：Linux 部署包使用本机沙箱（bubblewrap），Docker 部署与 Windows 部署包使用 Docker 任务容器。任务运行期间，群内日常聊天照常进行。

后台任务默认关闭，日常聊天、查资料和记忆功能不依赖它。

## 启用步骤

1. 进入面板**能力 → 后台任务**，打开**启用后台任务**。面板按部署方式预填运行环境：

   | 部署方式 | 运行方式 | 预填内容 |
   |---|---|---|
   | Linux 部署包 | **Linux 本机沙箱** | `bwrap` 程序路径与任务运行时目录 |
   | Docker 部署 | **Docker 任务容器** | 同版本的 `ghcr.io/lendevs/lenbot-worker` 镜像，任务目录放在 `lenbot-data` 数据卷内 |
   | Windows 部署包 | **Docker 任务容器** | Docker Desktop 地址 `npipe:////./pipe/docker_engine` 与同版本镜像 |

   本机沙箱点击**检查本机沙箱**，依次确认 bwrap、用户命名空间、任务运行时、沙箱读写和 Pi 启动，失败的步骤附原始输出，可改用 Docker 任务容器。Docker 任务容器点击**检查 Docker**，镜像不在本机时点击**拉取镜像**。
2. 选择**任务模型是否支持推理**后保存并重启。任务默认跟随聊天模型；如需独立编程模型，在**模型 → 用途**中配置**后台任务**（`worker`）。
3. 页面顶部的清单逐项列出运行方式、任务模型、群聊和文件发送的状态，缺少的项附跳转：
   - 在**群聊 → 设置**中开启**允许委托任务**，并在权限矩阵中勾选可以**委托任务**的成员身份；
   - 在**角色 → 工具与技能**中允许 `delegate`、`task`、`send_file` 与 `tool_search`；
   - 文件发送跟随发送方式，模拟发送时交付文件只在面板中下载，见下文[发送到 QQ](#发送到-qq)。
4. 群聊一项显示可以委托任务后，点击**运行示例任务**创建一个写入 `hello.txt` 并交付的任务，在群任务页查看过程和交付文件。

任务环境不能直接联网，模型请求、按联网方式放行的访问、浏览器操作与本群数据工具（记忆、资料、历史聊天查询、网页搜索与网页读取）都经由宿主进程代理。模型请求计入用量额度；联网访问、浏览器和网页工具的字节数计入流量上限；记忆、资料和历史聊天查询在本机完成，不计流量。API Key 始终留在宿主进程内。

数据工具跟随角色权限和任务的联网方式（`worker.egress.mode`）：

| 工具 | `off` | `allowlist` | `public` |
|---|---|---|---|
| `knowledge`（本群资料检索） | 角色允许且有资料时提供 | 角色允许且有资料时提供 | 角色允许且有资料时提供 |
| `web_read`（读取网页） | 不提供 | 只读 `allowed_hosts` 里的域名 | 提供 |
| `web_search`（网页搜索） | 不提供 | 不提供 | 提供 |

`web_read` 的目标网址、重定向的每一跳和服务返回的最终网址都按联网方式检查，不在清单内的结果被丢弃；这些访问在任务的联网记录里列为连接，字节数计入任务与群每日上限。任务事件为每次调用记一条 `data_tool`。

## 任务环境

任务里的 `python3` 预装 pandas、openpyxl、matplotlib、python-docx、pypdf 和 Pillow，不联网也能处理 CSV、XLSX、图表、DOCX 和 PDF；matplotlib 已配置中文字体。Node 的 `fetch()` 在开启联网时同样经任务代理访问。

| 运行方式 | pandoc、ffmpeg、poppler 与中文字体 | 网页渲染 `lenbot-render` 与浏览器 |
|---|---|---|
| Docker 任务容器 | 镜像内置 | 镜像内置 |
| Linux 本机沙箱 | 使用系统已安装的版本 | 不提供，需要时改用 Docker 任务容器 |

每个任务启动时，环境说明列出这个环境实际有的程序和库（`programs`），内置技能按同一份清单加载：

| 内置技能 | 加载条件 |
|---|---|
| `pdf`、`presentation`、`skill-writing`、`group-summary` | 始终 |
| `html-document` | 有 `lenbot-render` |
| `media-processing`、`media-analysis` | 有 `ffmpeg` |
| `spreadsheet`、`data-analysis`、`word-document` | 有对应的 Python 库 |
| `web-research` | 联网方式不是**不联网** |
| `public-browser` | 联网方式不是**不联网**，且有 `lenbot-browser` |

**能力 → 后台任务**里的**自定义技能目录**存放自定义技能：群共享技能放在 `shared/` 下，本群技能放在 `scenes/<群目录>/` 下，保存后与内置技能一起提供给任务。

## 联网方式

在**能力 → 后台任务 → 任务能力**中选择任务的**联网方式**：

| 联网方式 | 任务能连接的地址 |
|---|---|
| **不联网**（默认） | 只能经宿主调用模型 |
| **按域名放行** | 只连**可连接的域名**中的域名；`*.example.com` 匹配它的所有子域名，不含 `example.com` 本身；不能直接连 IP 地址。**加入软件包源**一次填入 `pypi.org`、`files.pythonhosted.org`、`registry.npmjs.org` |
| **公网** | 公网地址；内网、环回和保留地址始终不可连接 |

三种方式都受**更多限制**中的流量、速度和连接数上限约束，每个任务的上传量另有上限（默认 20 MB）。被拒绝的连接及原因记入任务事件，任务可用 `network_status` 读取。浏览器 `lenbot-browser` 跟随联网方式：不联网时不可用，按域名放行时只能打开名单内的网站。本地 HTML 渲染 `lenbot-render` 离线运行，不受联网方式影响。

## 磁盘空间

- 每个任务的工作区与运行目录合计不超过**每个任务的目录大小上限**（默认 2 GB），超过时任务停止并记录原因。
- 任务目录所在磁盘剩余空间低于 5 GB 时不接收新任务，已排队的任务等空间恢复后再开始；低于 2 GB 时停止运行中的任务。
- 任务结束 14 天后自动删除工作区与运行目录，交付文件和任务记录保留。
- 以上数值都在**更多限制**中调整。

## 日常使用与空间管理

在**群聊 → 任务**页签下可通过四个视图管理单群工作流：

- **资料输入**：在**任务空间与文件**视图中可上传**本群共享资料**，也可从历史任务的工作区或交付副本中挑选文件（单个新建任务最多挂载 16 份只读输入快照）。
- **实时预览、提问与续接**：任务执行期间可在面板查看实时输出流与每一步操作事件。任务需要发起人确认方案或补充信息时会进入**等待回答**状态（等待期间不占用并发运行槽位）；任务完成后，只要工作区尚未释放，群友或运营者均可追加要求按原会话和原目录**继续任务**。
- **网页渲染**：Docker 任务容器内置无头渲染工具 `lenbot-render`，可将生成的 HTML 页面直接导出为排版好的 PDF 或高清长截图。
- **任务编写的技能**：任务在执行过程中编写的可复用技能可在任务详情的**更多 → 任务编写的技能**中审阅，并一键采纳移入**本群**或**共享**技能库（之后可在**能力 → 技能**中管理）。
- **分级清理空间**：在**任务空间与文件**中可按时间筛选任务并计算磁盘用量。**清理临时文件**仅移除控制管道、运行日志和浏览器临时目录，保留工作区与会话供后续续接；**释放环境**彻底删除工作区和运行目录（不可再续接），已登记的交付副本、本群共享资料和数据库任务记录仍然保留。

## 发送到 QQ

任务在容器内产出文件后，**登记为交付**与**发送到 QQ** 是两个独立步骤。登记后的交付文件可在面板中预览下载，聊天模型调用 `send_file` 把它上传为 QQ 群文件或私聊文件。

LenBot 把文件内容以 `base64://` 随上传请求发给 OneBot 协议端，协议端与 LenBot 不需要共用目录，分处两台机器或两个容器都可以。单个文件最大 36MiB。每次上传的回执（成功、明确失败或结果未知）记录在任务事件中。

## 重启与版本更新

重启 LenBot 会中断当时正在运行的任务，并将其状态记为中断；工作区文件与任务会话完整保留，重启后可直接续接，排队中的任务保留原队列顺序。

部署包与 Docker 部署更新版本时，官方 worker 镜像随之切换到同一版本：更新器在更换前拉取镜像，直接用新镜像启动的 Docker 容器只改配置，镜像在面板中点击**拉取镜像**或用 `docker pull` 获取。Linux 本机沙箱的任务运行时随部署包更新。
