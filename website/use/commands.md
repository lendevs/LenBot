# 群内命令与权限

以 `/` 开头的内置命令由宿主直接解析执行，不调用聊天模型。命令前允许带有引用回复或 `@` Bot。所有命令消息照常写入聊天记录，后续回合中模型可以看到群内执行过哪些命令。

## 内置命令列表

| 命令 | 可用身份 | 作用 |
|---|---|---|
| `/help` | 所有非黑名单成员 | 列出当前发送者有权限使用的命令 |
| `/id` | 所有非黑名单成员 | 返回当前场景标识符、发送者账号和 Bot 账号，便于配置权限名单 |
| `/status` | 本群聊天管理 | 查看本群聊天开关、安静状态、最近一小时发言计数与当前聊天模型 |
| `/quiet <分钟>`、`/quiet <分钟> defer` | 本群聊天管理 | 让本群进入临时安静（最长 7 天）；默认期间被 `@` 仍照常回复，附加 `defer` 则延后至安静结束再回复 |
| `/resume` | 本群聊天管理 | 提前结束本群的临时安静状态 |
| `/chat on`、`/chat off` | 主人与全局管理员（可选开放给群主和群管理员） | 开启或关闭本群聊天；关闭期间消息仅做记录，重新开启后不补回期间消息 |
| `/reset` | 主人与全局管理员（可选开放给群主和群管理员） | 开启全新对话上下文，历史聊天原文、长期记忆与定时提醒均保留 |
| `/model` | 主人与全局管理员 | 查看当前聊天模型绑定的服务商与模型名 |
| `/limit`、`/limit <条数>`、`/limit off`、`/limit global`、`/limit reset` | 主人与全局管理员 | 查看本群每小时发言余量；将本群上限设为指定条数、不限或跟随全局；立即清零最近一小时发言计数 |
| `/角色`、`/角色 <名字>` | 主人与全局管理员 | 列出当前角色与可切换角色，或切换为指定名字、别名或文件夹名的角色 |

插件注册了同名命令时优先由插件处理（包括插件显式注册 `/角色` 的情况）。无权限成员发送管理命令时，宿主不会返回报错提示，该条消息按普通群聊消息交由注意力与对话流程处理；处于黑名单中的账号发送任何消息或命令均被忽略。

## 权限体系

LenBot 区分五级成员身份与黑名单：

- **主人（`owner`）**：全局最高权限，在**系统 → 设置 → 全局权限**中配置。
- **管理员（`admin`）**：包含**系统 → 设置 → 全局权限**中的全局管理员，以及**群聊 → 设置 → 权限 → 本群附加名单**中的本群管理员。
- **群管理（`group_manager`）**：QQ 群的群主与群管理员（由平台事件实时识别）。
- **白名单（`whitelist`）**：全局白名单与本群附加白名单成员。
- **群友（`member`）**：群内其他普通成员。
- **黑名单（`blacklist`）**：全局或本群黑名单账号，Bot 忽略其消息、命令与唤醒。

在**群聊 → 设置 → 权限**的**权限矩阵**中，可按上述五种身份分别勾选本群的七项操作许可：委托任务、任务执行超过 30 分钟、管理他人的任务、为自己创建提醒、为他人创建提醒、管理他人的提醒、**在群内让 Bot 临时安静**。

其中：

- **在群内让 Bot 临时安静**一栏勾选的身份即上表中的**本群聊天管理**（默认包含主人、管理员和群管理），同时控制 `/status`、`/quiet`、`/resume` 命令与聊天中的 `scene_control` 工具。
- **仅对任务或提醒生效的名单**可为个别成员单独授予本群任务或提醒方向的管理员／白名单身份，或从黑名单中单独排除。
- `/chat on|off` 与 `/reset` 默认仅限主人和全局管理员使用；在**系统 → 设置 → 群聊 → 群内命令**中勾选**允许群主和群管理员使用 `/chat on|off` 和 `/reset`**（对应配置 `commands.group_managers_chat_reset: true`）并保存后，各群群主和群管理员也可在本群执行这两条命令，保存后立即生效。

## 命令发言计数与开关

`/help` 和 `/id` 的回复计入本群每小时发言上限（不动用被 `@` 额外余量），发言额度耗尽后不再响应，且同一发送者在 30 秒内重复发送相同命令只回复一次。其余管理命令的回复均不计入发言上限，确保群聊限流期间管理员仍可执行 `/quiet`、`/limit reset` 等操作。

需要在全局禁用部分或全部内置斜杠命令时，可在停机后编辑 `lenbot.config.json` 的 `commands` 字段：

```json
"commands": { "enabled": true, "disabled": ["limit"], "group_managers_chat_reset": false }
```

`enabled` 设为 `false` 关闭全部内置斜杠命令；`disabled` 填写需单独关闭的命令名（不含 `/`）。

## 主人在群内自然语言改设置

当本群角色允许 `host_manage` 与 `tool_search` 工具时，主人和全局管理员可以直接在群内用自然语言指示 Bot 查看或修改运行设置（QQ 群主与群管理员无此权限）。

支持在群内调整的范围包括：

- 各群聊天开关、参与方式、等待参数与群内学习开关
- 提醒开关、后台任务配额与群角色绑定
- 网页搜索与读取参数、本地记忆召回与整理阈值
- 模型生成参数（超时、思考强度）与每日 token 上限、每小时发言上限
- 数据保留天数
- 已安装插件的启用／停用、常规参数与启用群列表

涉及安全边界的配置（API Key 与访问令牌、主人与权限名单、OneBot 与面板监听地址、需停机迁移的存储路径）不可通过群内对话修改。Bot 修改需重启生效的设置后默认仅保存配置，只有在主人明确要求重启时才会触发宿主重启。

所有管理类工具均强制校验真实触发消息（`source_message_id`）：宿主直接从数据库读取该条消息的真实平台发送者核验身份，不接受模型自行编造请求人账号。
