# 资料检索

Bot 在群里回答问题时可以查资料，包括角色资料和本群资料文件。回答引用资料内容时会带上文件名和小节或页码。

## 两类资料

| | 角色资料 | 本群资料 |
| --- | --- | --- |
| 存放位置 | 角色包的 `knowledge/` | 实例的 `state/reference/scenes/<群>/` |
| 能查到的群 | 使用这个角色的群 | 只有这个群 |
| 管理位置 | **角色 → 资料** | **群聊 → 资料** |
| 格式 | Markdown | Markdown、纯文本、PDF |

本群资料只在本群可见，其他群即使使用同一个角色也查不到。角色资料的写法见[角色](./personas)。

## 添加本群资料

在**群聊 → 资料**中添加：

- **上传资料**：从电脑选择文件，可以一次选多份。
- **从群文件选择**：QQ 群聊可以浏览群文件和文件夹，点**加入资料**下载到本群资料。已加入的文件显示**已在资料中**，再点**更新**会用群文件里的版本替换。每个文件夹最多列出 200 个文件。
- 直接把文件复制到 `state/reference/scenes/<群>/`，打开资料页签时开始处理。

同名文件会被替换。单个文件最大 50MB，纯文本和 Markdown 最大 10MB。PDF 需要有文字层，扫描件无法读取。

## 处理状态

| 状态 | 含义 |
| --- | --- |
| 处理中 | 正在读取和切分文件 |
| 已索引 | 可以检索，显示字数、页数和段数；配置向量模型后同时显示已生成向量的段数 |
| 失败 | 显示原因，例如格式不支持或 PDF 没有文字层 |

**重新处理**会重新读取未改动的文件。**角色 → 资料**也会显示每个文件的处理状态。

## Bot 怎么查资料

- 角色有资料或本群有资料文件时，Bot 可以使用查资料工具 `knowledge`，按关键词检索、列出文件或分页阅读全文。
- 默认使用全文检索。配置向量模型后同时按意思检索，见[模型与用量](./models#向量检索)；向量接口请求失败时这一次只用全文检索。
- 资料更新或删除后，会话在下一次请求前收到提示：已更新的文件以新内容为准，已删除的文件不再使用。
- 工具调用和返回内容可以在**群聊 → 现场**中查看。
