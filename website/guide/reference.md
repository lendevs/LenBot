# 资料检索

Bot 回答问题时可通过 `knowledge` 工具检索参考资料，涵盖角色包自带的设定资料与单群上传的本群资料。检索结果附带文件名及小节标题或 PDF 页码，便于模型按原文准确作答。

## 两类资料对比

| 维度 | 角色资料 | 本群资料 |
|---|---|---|
| 存放目录 | 角色包下的 `knowledge/` | 实例目录下的 `state/reference/scenes/<群目录>/` |
| 可见范围 | 所有绑定该角色的群共享 | 仅当前群可见，使用同一角色的其他群不可见 |
| 面板入口 | **角色 → 资料** | **群聊 → 资料** |
| 支持格式 | Markdown（`.md`、`.markdown`） | Markdown（`.md`、`.markdown`）、纯文本（`.txt`）、带文字层的 PDF（`.pdf`） |

角色设定资料的组织建议见[写角色包](../develop/personas#事实资料)。

## 添加与更新本群资料

在**群聊 → 资料**页签可通过三种方式维护文件：

- **上传资料**：从本地电脑一次选择一份或多份文件上传，同名文件直接覆盖更新。
- **从群文件选择**：浏览当前 QQ 群的群文件与子文件夹（单文件夹最多列出 200 项），点击**加入资料**直接拉取入库；已入库文件显示**已在资料中**，群文件有新版本时点击**更新**即可覆盖。
- **直接放入目录**：将文件复制到 `state/reference/scenes/<群目录>/`（忽略隐藏文件与符号链接），下次打开资料页签或模型发起查询时自动扫描入库。

单个 PDF 文件上限为 50 MB，纯文本与 Markdown 文件上限为 10 MB。PDF 需包含可提取的文字层，纯图片扫描件不会执行光学字符识别（OCR）。

## 索引与处理状态

| 状态 | 含义 |
|---|---|
| 处理中 | 正在提取文本并按约 600 字切分检索段落 |
| 已索引 | 可供全文检索，展示总字数、PDF 页数和切分段数；配置向量模型后同时展示已生成向量的段数 |
| 失败 | 提取失败并展示具体原因（例如超出大小上限或 PDF 无文字层） |

点击单份文件旁的**重新处理**可强制重新提取。**角色 → 资料**页同样展示每份设定文档的字数与分段状态。

## 检索机制

- 当角色存在设定资料或本群存在资料文件，且角色工具许可允许 `knowledge` 时，聊天模型可按关键词检索片段、列出资料清单，或按字符区间与页码分段阅读原文。
- 模型已知目标文件名时可通过 `filename` 参数限定单文件检索，也可通过 `scope` 参数指定只查角色资料（`persona`）、只查本群资料（`chat`）或同时检索两者（`all`）。
- 未配置向量模型时使用 SQLite FTS5 三元组（trigram）全文检索；在**模型 → 向量模型**中配置**记忆和资料向量**后自动启用全文与向量混合检索（向量按查询批次渐进补齐，接口临时出错时当次自动回退全文检索），详见[模型与用量](./models#向量检索)。
- 资料文件发生更新或删除后，宿主会在该群下一轮模型请求前注入变更提示，告知模型以新版本为准并停用已删除文件的内容。
