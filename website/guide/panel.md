# 面板一览

管理面板默认监听 `http://127.0.0.1:8088`，仅限本机访问。通过 SSH 端口转发或反向代理从其他设备访问的方式见[首次配置](./first-setup#从其他机器打开面板)。

## 导航结构

左侧主导航按日常高频操作与低频系统配置分为四组：

| 分组 | 页面 | 用途 |
|---|---|---|
| 运行 | 总览 | 连接与发送状态切换、今日消息与 token 统计、待处理事项、各群实时动态、运行健康 |
| | 对话测试 | 基于现有群聊设置或角色草稿启动隔离试聊，全部回复仅在页面内展示 |
| 群聊 | 群聊 | 按群查看现场时间线、会话回想、长期记忆、本群资料、任务与提醒、群内学习及单群设置 |
| | 角色 | 编辑角色设定、说话方式与轮换风格、资料、表情、工具与技能许可，支持草稿试聊与提示词预览 |
| 扩展 | 插件 | 从目录、Git 或 ZIP 安装插件，填写配置表单、分配使用的群、查看日志、更新或回退版本 |
| | 能力 | 管理 MCP 服务、后台任务技能、网页搜索与读取服务、Docker 后台任务环境 |
| 配置 | 模型 | 管理模型服务商连接、各用途模型绑定、向量模型、token 用量统计与每日额度上限 |
| | 系统 | **设置**（连接、全局权限、群聊、面板账号、数据保留、提示词、版本与更新、高级）与**日志**（系统日志、运行健康） |

顶栏右侧依次排列：**快速跳转**、发送方式徽标、平台连接状态、待处理通知与**账号菜单**。按下 `⌘K`（macOS）或 `Ctrl+K`（Windows／Linux）可随时唤起快速跳转框，直接切换页面、跳转指定群聊、暂停或恢复某群聊天，或为某群切换角色。账号菜单支持切换界面外观（跟随系统／浅色／深色）、界面语言（中文／English）、重启 LenBot 与退出登录。

## 群聊工作台

**群聊**页左侧列出已接入的全部群聊和私聊，支持按名称、号码或角色筛选；点击 **+**（接入群聊）可从 Bot 已加入的 QQ 群列表中勾选接入，也可手动输入群号或私聊 QQ 号，保存后立即生效。

右侧为当前选中群的工作台：顶栏展示群名、人数、当前角色（点击即可切换角色）、聊天状态标签与聊天开关；右上角 **…**（更多操作）菜单提供**临时安静**、**开始新会话**和**使用本群设置试聊**三项快捷操作。

![群聊页的现场页签：左侧选择群，右侧是群消息和 Bot 的回合](/screenshots/scenes.png)

工作台下设七个页签：

| 页签 | 内容 |
|---|---|
| 现场 | 群消息流与 Bot 的回合卡片，支持筛选**只看回合**或**只看出错**，右上角可查看**语音转写**队列与记录 |
| 会话 | 当前会话的**回想**摘要与实际送入模型的上下文条目，支持手动点击**整理回想** |
| 记忆 | **浏览**、**搜索**、**后台整理**、**索引**与**设置**五个视图，详见[记忆与学习](./memory) |
| 资料 | 上传本群资料、从 QQ 群文件导入、查看分段与向量状态，详见[资料检索](./reference) |
| 任务 | **任务**、**提醒**、**主动发起话题**与**任务空间与文件**四个视图，详见[后台任务](./tasks) |
| 学习 | 审核与管理学到的**说法**、**黑话**、**表情**和**回复效果**，以及单群学习参数 |
| 设置 | 本群角色、参与方式、每日安静时段、每小时发言上限、主动发起话题、本群的称呼与额外要求、提醒与任务、本群启用的插件、权限、移除群聊 |

### 现场时间线与回合卡片

现场时间线中，群友消息居左，Bot 发言居右。每条群友消息旁带有唤醒判定图标：闪电代表唤醒了回合，月亮代表未唤醒，点击可查看唤醒渠道、参与分、门槛及回复效果系数。

Bot 每执行一轮决策就生成一张回合卡片。折叠态摘要展示唤醒渠道、步数、发言条数、首句耗时、输入／输出 token 与调用的工具；展开后完整列出本轮自动召回的记忆条目，以及每一步的模型思考内容、工具参数、返回结果或错误原文。

![Bot 被 @ 后，回合卡片逐步展开：先查询聊天记录，再分两条回复](/screenshots/live.gif)

## 账号与场景标识符格式

在权限名单、成员关系或提醒对象中填写身份时，统一使用带平台前缀的完整标识符：

```text
onebot:90001          个人或 Bot 账号（平台:号码）
onebot:group:80001    QQ 群聊（平台:group:群号）
onebot:private:70001  QQ 私聊（平台:private:对方号码）
```

## 设置生效时机与重启

面板中的设置按影响范围分为三类生效方式：

- **保存即生效**：发送方式切换、单群聊天开关与全部暂停、接入或移除群聊、参与方式与活跃度、每日安静时段、每小时发言上限、每日 token 上限、全局与单群权限名单、数据保留策略、日志参数等。
- **当前回合结束时生效**：编辑在用角色、为群切换角色、切换已在群内运行的**长期记忆**或**压缩回想**插件。若该群当前没有进行中的回合则立即切换；正在回复时等本轮收尾后无缝切换。
- **重载插件或重启宿主生效**：修改 `reload = "plugin"` 插件的参数或启用群时，宿主仅热重载该插件；修改 OneBot 连接、面板端口与账号、模型服务商与用途绑定、向量模型配置、MCP 服务、Docker 后台任务环境、框架提示词或需安装新 Python 依赖的插件时，顶栏会提示**已保存，重启后生效**。

在面板点击**重启**时，对话框会先列出待应用的修改项以及当前受影响的活动：进行中的群聊回合会先等待完成，执行中的后台任务会安全中断并保留工作区以便重启后按原编号续接，排队中的任务保留，进行中的试聊停止。新宿主进程就绪后自动跳转登录页。

## 框架提示词覆盖

**系统 → 设置 → 提示词**支持查看和覆盖 `src/len_bot/prompts/` 下的框架提示词模板，修改对所有群生效，保存并重启后应用。

模板中形如 `$name` 的变量由宿主在运行时替换，保存前系统会校验占位符集合与默认模板完全一致；正文需要字面量 `$` 时写作 `$$`。

自定义修改保存在实例目录的 `state/prompts/` 下。升级 LenBot 版本时，更新器默认将旧版自定义提示词移至 `state/prompts/.replaced/` 并启用新版内置提示词；若开启**更新 LenBot 后保留这些修改**，升级后继续沿用自定义文件，并在面板中提示该文件基于哪个旧版本编写以便对照核查。
