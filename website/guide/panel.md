# 面板一览

面板默认地址是 `http://127.0.0.1:8088`，只监听本机。从其他机器访问的方法见[首次配置](./first-setup#从其他机器打开面板)。

## 导航

| 分组 | 页面 | 用途 |
|---|---|---|
| 运行 | 总览 | 连接状态、当日统计、待处理事项、各群实时动态、运行健康 |
| | 对话测试 | 用某个群的设置或某个角色试聊，回复只显示在页面上 |
| 群聊 | 群聊 | 每个群的现场、会话、记忆、资料、任务、学习和设置 |
| | 角色 | 设定、说话方式、资料、表情、工具与技能、使用的群，修改后可以先试聊 |
| 扩展 | 插件 | 安装、配置和更新插件，选择在哪些群使用 |
| | 能力 | MCP 服务、技能、网页、后台任务 |
| 配置 | 模型 | 服务商、各用途的模型、向量模型、用量与上限 |
| | 系统 | 设置（连接、全局权限、群聊、面板账号、数据保留、提示词、版本与更新、高级）和日志 |

顶栏右侧依次是快速跳转、发送方式、连接状态、通知和账号菜单。快速跳转（`⌘K` 或 `Ctrl+K`）可以跳到页面或群聊，也可以直接暂停、恢复某个群，或给群切换角色。账号菜单中可以切换外观和语言、重启 LenBot、退出登录。

## 群聊工作台

群聊页左侧是已接入的群，可以按群名、群号或角色名搜索，点击 **+** 接入新的群，接入立即生效。右侧是选中群的工作台，顶部显示群名、群号、人数、当前角色和聊天状态。点击角色名可以切换角色，右上角是聊天开关，***…** 菜单中有**临时安静**、**开始新会话**和**使用本群设置试聊**。

![群聊页的现场页签：左侧选择群，右侧是群消息和 Bot 的回合](/screenshots/scenes.png)

| 页签 | 内容 |
|---|---|
| 现场 | 群消息和 Bot 的每一个回合。可以只看回合或只看出错，语音转写结果在右上角 |
| 会话 | 回想和当前会话中交给模型的全部内容，可以手动整理回想 |
| 记忆 | 浏览、搜索、后台整理、索引和记忆设置 |
| 资料 | 本群资料文件：上传、从群文件选择、更新、删除和处理状态，见[资料检索](./reference) |
| 任务 | 后台任务、提醒、主动开话题、任务空间与文件 |
| 学习 | 学到的说法、黑话、表情和回复效果，以及学习设置 |
| 设置 | 角色、参与方式、安静时段、发言上限、主动开话题、称呼与额外要求、提醒与任务、插件、权限、移除群聊 |

### 现场

群友的消息在左，Bot 的发言在右。Bot 每处理一个回合，消息流中出现一张回合卡片。折叠时显示唤醒方式、步数、发言条数、耗时、token 和用到的工具；展开后按顺序列出召回的记忆，以及每一步的模型调用、想法、正文、工具参数和结果。回合进行中卡片实时更新，出错时标红并显示原始错误。

![Bot 被 @ 后，回合卡片逐步展开：先查询聊天记录，再分两条回复](/screenshots/live.gif)

## 账号和场景的写法

在面板中填写账号时（例如主人和白名单），账号写作 `平台:账号`，群写作 `平台:group:群号`，私聊写作 `平台:private:账号`。

```text
onebot:90001          Bot 自己
onebot:70001          主人
onebot:group:80001    群
onebot:private:70001  与主人的私聊
```

## 权限

- **系统 → 设置 → 全局权限**：主人、全局管理员、白名单和黑名单，对所有群生效。
- **群聊 → 设置 → 权限**：为本群附加名单，并设定谁可以委托任务、创建提醒和让 Bot 临时安静。

## 保存与重启

插件参数和插件启用的群保存后，只重新加载该插件，聊天不中断。其他需要重启的设置保存后，顶栏提示有待应用的修改。

点击重启时，面板先列出受影响的设置和正在进行的工作。确认后：

- LenBot 停止接收新消息和新工作，等当前回合完成后停止。
- 后台任务中断，会话和文件保留，之后可以续接。
- 试聊停止。
- 新进程启动后需要重新登录面板。

LenBot 异常退出后，根据终端输出或服务日志处理原因，再重新启动。

## 框架提示词

**系统 → 设置 → 提示词**可以修改 LenBot 自带的提示词，例如判断是否回复、如何使用工具。修改对所有群生效，重启后应用。需要还原时点击**恢复默认**。

带 `$` 的占位符（如 `$name`）由 LenBot 在运行时填入，修改后必须保留与默认内容相同的一组占位符，否则无法保存。正文中需要字面的 `$` 时写作 `$$`。

修改保存在实例目录的 `state/prompts/` 中。升级到新版本时，默认把这些修改移到 `state/prompts/.replaced/`，改用新版本自带的提示词；勾选**更新 LenBot 后保留这些修改**后继续使用这些修改，面板会提示它们基于哪个旧版本。
