# 面板一览

面板左侧的导航分成四组。

| 分组 | 页面 | 用途 |
|---|---|---|
| 运行 | 总览 | 连接状态、今天的统计、需要处理的事、各群实时动态、运行健康 |
| | 对话测试 | 用某个群的设置或某个角色试聊，回复只显示在页面上 |
| 群聊 | 群聊 | 每个群的现场、会话、记忆、任务、学习和设置 |
| | 角色 | 设定、说话方式、资料、表情、工具与技能、用在哪些群，修改后可以先试聊 |
| 扩展 | 插件 | 安装、配置和更新插件，选择在哪些群使用 |
| | 能力 | MCP 服务、技能、网页、独立任务、账号浏览器 |
| 配置 | 模型 | 服务商、各用途的模型、向量模型、用量与上限 |
| | 系统 | 设置（连接、全局权限、群聊、面板账号、数据保留、提示词、版本与更新、高级）和日志 |

顶栏右侧依次是快速跳转、发送方式、连接状态、通知和账号菜单。快速跳转（`⌘K` 或 `Ctrl+K`）可以跳到页面或群聊，也可以直接暂停、恢复某个群，或者给群换角色。账号菜单里可以切换外观和语言、重启 LenBot、退出登录。

## 群聊

群聊页左侧是已接入的群，可以按群名、群号或角色名搜索，点 **+** 接入新的群。接入立即生效，不需要重启。右侧是选中群的工作台，顶部显示群名、群号、人数、当前角色和聊天状态。点角色名可以给这个群换角色，右上角是聊天开关，**…** 菜单里有**安静一会**（或**现在恢复**）、**开始新会话**和**带这个群的设置去试聊**。

![群聊页的现场页签：左侧选择群，右侧是群消息和 Bot 的回合](/screenshots/scenes.png)

工作台有六个页签。

| 页签 | 内容 |
|---|---|
| 现场 | 群消息和 Bot 的每一轮回复。可以只看回合或只看出错，语音转写结果在右上角 |
| 会话 | 回想和当前会话里交给模型的全部内容，可以手动整理回想 |
| 记忆 | 浏览、搜索、后台整理、索引和记忆设置 |
| 任务 | 后台任务、提醒、主动开话题、任务空间与文件 |
| 学习 | 学到的说法、黑话、表情和回复效果，学习设置 |
| 设置 | 角色、参与方式、安静时段、发言上限、主动开话题、称呼与额外要求、提醒与任务、插件、权限、移除群聊 |

### 现场

群友的消息在左，Bot 的发言在右。群友消息时间后的小图标表示这条消息有没有叫醒 Bot：闪电是叫醒了，月亮是没有。悬停可以看原因，点开可以看叫醒方式、参与分和门槛。

Bot 每回复一轮，消息流里就出现一张回合卡片，折叠时显示叫醒方式、步数、发言条数、耗时、token 和用到的工具。展开后按顺序列出召回的记忆，以及每一步的模型调用、想法、正文、工具参数和结果。回合进行中时卡片实时追加，出错时标红并显示原始错误。

![Bot 被 @ 后，回合卡片逐步展开：先翻聊天记录，再分两句回复](/screenshots/live.gif)

## 账号和群的写法

在面板中填写账号时（例如主人和白名单），账号写成 `平台:账号`，群写成 `平台:group:群号`，私聊写成 `平台:private:账号`。目前只有 OneBot 一个平台。

```text
onebot:90001          Bot 自己
onebot:70001          主人
onebot:group:80001    群
onebot:private:70001  和主人的私聊
```

## 权限

权限分两处设置。

- **系统 → 设置 → 全局权限**中是主人、全局管理员、白名单和黑名单，对所有群生效。
- **群聊 → 设置 → 权限**可以为本群另外添加名单，并按群设定谁可以委托任务和设置提醒，谁可以让 Bot 暂时安静。

## 总览和群聊的快捷操作

### 群聊开关

总览群聊列表和群聊工作台右上角的开关。关闭后，这个群的消息照常记录，但 Bot 不回复也不主动发言，被 @ 时同样不回复，插件也不在这个群响应。重新打开后，Bot 从新消息开始处理，不会补回关闭期间的消息。

### 全部暂停

总览顶部状态卡上的按钮。一次关闭所有群的聊天开关，消息照常记录，不调用模型，适合模型额度用完时使用。全部关闭后按钮变为**全部恢复**，点击后打开所有群。

### 发送方式

真实发送到 QQ 时，总览状态卡上有**发到 QQ**和**模拟发送**两个选项。选择模拟发送后，Bot 照常回复，但回复只记录为模拟发送，不发到 QQ，群友看不到；贴表情也只记录。模拟的发言照样计入每小时发言上限。重启后保持原状态。改回**发到 QQ**后，之后的回复重新发到 QQ，之前模拟的内容不会补发。

这个选项是临时的。首次配置时选了模拟发送、要长期改为真实发送时，在**系统 → 设置 → 连接**的**发送方式**中修改。

只想让某几个群不发言时，在配置文件里给这些群写 `"simulated_delivery": true`，效果和这个开关相同，只作用于这些群，重启后生效。

### 断开 QQ

在总览状态卡的 **…** 菜单中。立即关闭 OneBot 连接。正在进行的回复和后台任务会中断，面板仍然可以使用。需要重新连接时，在右上角的账号菜单中点击重启。

### 手动连接 QQ

只在启动时第一次连接失败后出现在总览状态卡上。修复 OneBot 的问题后点击这个按钮。运行期间断线时 LenBot 会自动重连，不需要这个按钮，见[断线以后](./onebot#断线以后)。

## 保存与重启

插件参数和插件启用的群保存后，只重新加载这个插件，聊天不会中断。其他需要重启才能生效的设置，保存后顶栏会提示有待应用的修改。

聊天模型、协议和服务商名称可以直接修改并保存。更换向量地址、模型或维数时，已有索引需要[重建索引](./memory#重建索引)。

点击重启时，面板会先列出受影响的设置和正在进行的工作。确认重启后会发生以下变化。

- LenBot 不再接收新消息和新工作。正在进行的这一轮回复完成后才停止。
- 后台任务中断，但会话和文件保留，之后可以继续。
- 账号浏览会话关闭，试聊停止。
- 新进程启动后，需要重新登录面板。

LenBot 异常退出后不会自动重新启动，请查看日志找出原因。在终端运行时查看终端输出，作为服务运行时查看服务日志，使用 Docker 时查看容器日志。

## 框架提示词

**系统 → 设置 → 提示词**可以修改 LenBot 自带的提示词，例如怎样判断要不要回复、怎样用工具。改动对所有群生效，重启后应用。改错可能让 Bot 不再回复或用错工具，不确定时点**恢复默认**。

带 `$` 的占位符（如 `$name`）由 LenBot 在运行时填入，修改后必须保留与默认内容相同的一组占位符，否则无法保存。正文里要写字面的 `$` 时写成 `$$`。

修改保存在实例目录的 `state/prompts/` 中。升级到新版本时，默认把这些修改移到 `state/prompts/.replaced/`，改用新版本自带的提示词；勾选**更新 LenBot 后保留这些修改**后，升级会继续使用这些修改，面板会提示它们基于哪个旧版本。

## 在群里修改设置

给角色的工具许可加上 `host_manage` 和 `tool_search` 并重启后，主人和全局管理员可以在群里直接让 Bot 修改设置，例如「把本群改成只回应 @ 吧」或「改完重启一下」。

可以修改的设置包括：

- 各群的聊天开关，以及聊天和学习参数
- 提醒和任务，以及角色绑定
- 网页和记忆参数
- 模型的生成参数和预算
- 数据保留
- 已安装插件的启用和停用，以及插件的普通参数和启用的群

不能修改密钥和身份授权，也不能修改连接方式和需要停机转换的设置。

默认情况下 Bot 只保存修改。只有明确要求重启时，Bot 才会重启。

## 群内命令

在群里发送以 `/` 开头的命令，LenBot 会直接回复，不经过模型。命令前面可以带引用或 @ Bot。命令消息照常记录，Bot 之后能看到谁用过什么命令。

所有人可用的 `/help` 和 `/id` 的回复计入每小时发言上限（不占被叫到时的余量），本群发言用完后不再回复；同一个人 30 秒内重复发送同一条命令只回复一次。其余命令的回复不计入发言上限，发言用完时管理员仍然可以用 `/quiet` 等命令。

| 命令 | 谁可以用 | 作用 |
|---|---|---|
| `/help` | 所有人 | 列出发送者可以用的命令 |
| `/id` | 所有人 | 显示本群、自己和 Bot 的账号，填写权限时用 |
| `/status` | 本群聊天管理 | 聊天开关、安静状态、最近一小时发言、主脑模型 |
| `/chat on`、`/chat off` | 主人和全局管理员；可选群主和群管理员 | 打开或关闭本群聊天。关闭期间消息照常记录，打开后只作为背景 |
| `/quiet <分钟>`、`/quiet <分钟> defer` | 本群聊天管理 | 本群临时安静，最长 7 天。默认被 @ 或回复时仍回应，加 `defer` 后也延后 |
| `/resume` | 本群聊天管理 | 提前结束临时安静，不影响设置里的安静时段 |
| `/reset` | 主人和全局管理员；可选群主和群管理员 | 开始新的对话上下文，与群聊工作台 **…** 菜单里的**开始新会话**相同。聊天记录和记忆都保留 |
| `/model` | 主人和全局管理员 | 查看主脑使用的服务商和模型。出错时不会自动更换模型或服务；更换主脑服务在**模型**页修改 |
| `/limit`、`/limit <条数>`、`/limit off`、`/limit global`、`/limit reset` | 主人和全局管理员 | 查看本群发言余量；设置本群每小时条数、不限或跟随全局，保存后立即生效；清空本群最近一小时的计数 |
| `/角色`、`/角色 <名字>` | 主人和全局管理员 | 列出现在的角色和可以换的角色；换成指定角色，名字可以写角色名、别名或目录名。回复不交给 Bot，Bot 从换角色的交接里知道 |

本群聊天管理默认包括主人、全局管理员和群主、群管理员，在**群聊 → 设置 → 权限**中修改「谁可以让 Bot 暂时安静」。这项设置只管 `/status`、`/quiet` 和 `/resume`。

`/chat` 和 `/reset` 的效果不会自动过期，默认只有主人和全局管理员可以用。根配置的 `commands.group_managers_chat_reset` 设为 `true` 后，群主和群管理员也可以在本群使用，不受「谁可以让 Bot 暂时安静」影响。没有权限的人发送命令时，Bot 不会公开拒绝，这条消息和普通消息一样交给 Bot。黑名单中的账号不能使用命令。

插件注册了同名命令时由插件处理。在根配置中可以关闭命令：

```json
"commands": { "enabled": true, "disabled": ["limit"], "group_managers_chat_reset": false }
```

`enabled` 为 `false` 时关闭全部命令，`disabled` 中列出单独关闭的命令名（不带 `/`），`group_managers_chat_reset` 默认 `false`。修改后重启生效。

## 用量与上限

总览的统计最多每 5 秒重新计算一次；运行状态照常即时刷新。统计、用量和回合详情在后台读取，不会在查询期间占住宿主的消息处理循环。

**模型 → 用量与上限**中显示今天和本月使用的 token 数量，也可以设置每天的 token 上限。总览显示的是同一个数字。数字来自模型服务的报告，LenBot 不换算成金额。

同一页的**叫醒与发言**按群、日期和唤醒方式列出叫醒次数、发言次数、发言率、主脑输入 token 和缓存命中 token，可以筛选群聊。一次轮次只算一次叫醒，一轮成功说话、发独立表情或给消息贴表情都算一次发言。输入 token 包含缓存命中；缓存命中列是其中的一部分。日期按实例时区划分，轮次中的所有主脑请求计入开轮那一天，其他模型用途仍在上方用量表查看。旧轮次没有保留唤醒标记时显示为历史未记录。

**群聊 → 设置 → 参与方式 → 等待与插话的细节**中的**对话继续时选择沉默，就结束继续留意**默认开启。Bot 说完话后会继续留意；一次因对话继续被叫醒的轮次选择旁听后，普通群聊消息改由插话打分决定是否叫醒。被 @、被回复和点名照常处理，Bot 下次说话或被直接叫醒后会重新继续留意。工具失败或轮次超时不会关闭。关闭这个开关可恢复原来的继续留意行为，保存后按面板提示重启生效。

有些服务不报告 token 用量，这类调用单独计数。设置上限以后，只要当天出现这类调用，LenBot 就无法确认是否超出上限，因此会暂停当天的模型调用。

## 每小时发言上限

为了避免 Bot 在一个群里说个不停，LenBot 会统计每个群最近 60 分钟内的发言次数。全局默认值在**系统 → 设置 → 群聊**中修改，默认每个群每小时 60 条。单个群在**群聊 → 设置 → 每小时发言上限**里选择跟随全局、自定义条数或不限。私聊不受这个上限限制。

计数规则如下。

- 一次发言算一条。一句话被拆成几条消息发出，或者文字带着表情，都只算一条。单独发一个表情也算一条，给消息贴表情不算。
- 插件发送的内容（例如日报卡片）不计数，也不会被这个上限拦下。
- 安静时段的固定回复和下面说的固定回复也不计数。

到达上限后，Bot 不再主动插话或开话题，被 @、被回复（私聊同理）、到点的提醒和后台任务结果仍然可以再说几条，默认 5 条，在**系统 → 设置 → 群聊**中修改。语音转写结果和插件推来的事件不算被叫到，和普通消息一样受上限限制；一次回答了 @ 之后，同一轮里接着进来的普通消息也不再使用余量。被上限打断的 @ 回合恢复时仍按被叫到处理，余量一空出来就回答。插件自己发送的内容不计数也不拦截。余量也用完后，这个群暂停发言，等最早的一次发言超过 60 分钟后自动恢复。未读消息会保留，恢复后一起处理。快到上限时，Bot 在回复前会看到本群还剩几条。

到上限后默认不在群里说明。需要的话，打开**全部用完后被 @，回一句固定的话**并填写内容，Bot 会原样发送，每次暂停最多发一次。

**群聊 → 设置**会显示本群最近一小时说了几条。到上限时，总览的需要处理的事会列出这个群，点**本小时临时放开**可以清零本群的计数。发言上限的修改保存后立即生效，不需要重启。
