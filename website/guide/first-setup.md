# 首次配置

LenBot 的配置和数据保存在实例目录里。实例目录中还没有配置文件 `lenbot.config.json` 时，LenBot 会先启动一个网页向导，并在终端输出它的地址；在本机桌面环境的终端里启动时，还会用浏览器直接打开。

```text
尚无根配置。请打开 http://127.0.0.1:52811/#token=...
```

向导只监听本机，端口每次随机分配。链接中的 `token` 只在本次启动有效。

向导会把已填写的内容暂存在浏览器标签页中，刷新页面不会丢失。密码和密钥不会暂存，刷新后需要重新填写，QQ 连接需要重新测试。

向导只在首次配置时出现，之后的修改都在面板里进行。

## 1. 管理员账号

填写面板用户名和密码，密码至少 8 位。每个实例只有这一个面板账号。

面板端口默认为 8088。面板只监听本机，安装在服务器上时需要通过 SSH 端口转发访问，方法见本页最后一节。

## 2. 连接 QQ

连接方式有两种。

- **LenBot 去连 OneBot**（正向 WebSocket）。填写 OneBot 地址，默认填好 `ws://127.0.0.1:3001`，按 OneBot 端实际的端口修改。两边在同一台机器上时，这种方式最简单。
- **等 OneBot 来连 LenBot**（反向 WebSocket）。填写 LenBot 的监听地址和监听端口，再在 OneBot 中把反向连接地址指向这里。

两种方式的区别和 OneBot 一侧的设置见[接入 QQ](./onebot)。

**访问令牌**要和 OneBot 中填写的一致，OneBot 没有设置时留空。反向连接监听 `127.0.0.1` 以外的地址时，必须设置访问令牌。

填写完成后，点击**测试连接**。LenBot 会连接 OneBot 并读取当前登录的 QQ 号，成功时显示「已连接，Bot 账号 …」。测试通过后才能进入下一步。

最后选择**发送方式**。第一次建议选择**模拟发送**。这时 Bot 照常接收消息并生成回复，但回复只显示在面板里。确认没有问题后，再到**系统 → 设置 → 连接**改为真实发送到 QQ。

## 3. 主人与时区

填写自己的 QQ 号。主人是这个 Bot 权限最高的用户，可以在群里直接让 Bot 改设置。其他主人可以之后在面板里添加。

时区默认为 `Asia/Shanghai`。提醒、安静时段和面板里显示的时间都按这个时区计算。

## 4. 聊天模型

这一步配置聊天使用的模型。看图、整理记忆、学习和后台任务默认也使用它，需要换用其他模型时在面板中配置，见[模型与用量](./models#模型用途)。

先选择 **DeepSeek**、**OpenAI 兼容**或**Anthropic 兼容**。三个入口都直接显示接口地址、Key 和模型名。DeepSeek 预填接口地址、`deepseek-flash`、思考强度和输出字段，地址可以修改；Anthropic 兼容预填官方地址、思考强度 `high` 并打开图片支持。填写连接后可以读取模型列表，按模型 ID 或名称搜索，也可以直接输入模型 ID，再按需测试模型。

**接话时少思考，回得更快（推荐）**：打开后，收到新消息后的第一次请求用 `low` 档思考，查完资料再用原来的思考强度。DeepSeek 和 Anthropic 兼容默认打开，OpenAI 兼容默认关闭。之后可以在**模型 → 用途**的聊天模型上开关。

**搜索服务**和**读取方式**分别选择，免费和付费的都有：

| 搜索服务 | 说明 |
|---|---|
| DeepSeek | 按次收费。可以复用 DeepSeek 聊天连接，也可以单独填写连接 |
| Tavily、Brave Search、博查 | 按次收费，填写各自的 Key |
| Yahoo、Bing RSS | 免费，不需要 Key |

| 读取方式 | 说明 |
|---|---|
| 本机直接读取 | 免费，由 LenBot 自己抓取网页并提取正文 |
| DeepSeek | 按次收费，复用 DeepSeek 搜索或聊天的连接 |
| Tavily | 按次收费，和 Tavily 搜索共用一个 Key |
| Jina Reader | 按用量收费，填写 Jina 的 Key |

搜索和读取选同一家时共用一个连接，选不同服务时分别填写。DeepSeek 搜索和读取的价格见[官方说明](https://api-docs.deepseek.com/zh-cn/guides/search/)。

**更多参数**中可修改代理、上下文长度、压缩阈值、输出额度、两档思考、图片支持和每轮步数，步数默认 16。**向量模型**是可选折叠区域；不配置时，本地记忆使用全文检索，之后可在**模型 → 向量模型**中添加。

## 5. 角色和第一个群

角色默认使用**小然**。选择**自己写一个**时，填写名字和人物设定，说话方式和底线可选。角色文件夹名在**更多设置**里，留空时名字是英文就用名字生成（例如 `Mika Chan` 生成 `mika-chan`），否则用 `my-bot`。

选择群聊并填写群号，或选择私聊并填写对方 QQ。在群里，Bot 一开始只回应 @ 它或回复它的消息；私聊中每条消息都会回复。其他群之后在面板里接入。

**官方插件**按需展开，勾选后在保存时安装。装好后在面板的插件页启用、修改设置，并选择在哪些群使用。插件安装失败时显示错误，可重试或取消选择。

## 保存之后

LenBot 按新配置启动，页面显示「正在启动 LenBot」。面板启动后，页面自动跳转到登录页。

如果面板一段时间后仍然没有响应，页面显示「配置已保存」和面板地址。通过 SSH 端口转发或反向代理访问时，本机看到的端口可能不同，请把地址改成实际访问的地址，再点击**打开面板**。这时请同时查看终端输出，常见原因是面板端口已被占用。配置已经写入，问题解决后重新启动 LenBot 即可，不需要再走一遍向导。

## 之后修改设置

所有设置都保存在实例目录的 `lenbot.config.json` 中，LenBot 只读取这一个文件。文件里有 API Key 和密码哈希，不要提交到 Git。

平时在面板里修改设置。有些设置需要重启才能生效，保存后页面顶部会提示。点击重启之前，面板会列出受影响的设置和正在进行的工作。如果要手动编辑这个文件，请先停止 LenBot。

## 从其他机器打开面板

面板默认只监听本机。需要从其他机器访问时，可以使用 SSH 端口转发。

```sh
ssh -L 8088:127.0.0.1:8088 你的服务器
```

然后在自己的电脑上打开 `http://127.0.0.1:8088`。如果要长期从外网访问，请在面板前面配置 HTTPS 反向代理。代理要保留 Host，并设置 `X-Forwarded-For` 和 `X-Forwarded-Proto`。代理不在 LenBot 这台机器上时，把代理的地址填进根配置的 `panel.trusted_proxies`。
