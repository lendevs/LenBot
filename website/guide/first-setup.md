# 首次配置

LenBot 的配置和数据保存在实例目录中。实例目录中没有配置文件 `lenbot.config.json` 时，LenBot 先启动网页向导并在终端输出其地址；在本机桌面环境的终端中启动时，同时用浏览器打开。

```text
尚无根配置。请打开 http://127.0.0.1:52811/#token=...
```

向导只监听本机，端口每次随机分配。链接中的 `token` 只在本次启动有效。

向导把已填写的内容暂存在浏览器标签页中，刷新页面不会丢失。密码和密钥不暂存，刷新后需要重新填写，QQ 连接需要重新测试。

向导只在首次配置时出现，之后的修改在面板中进行。

## 1. 管理员账号

填写面板用户名和密码，密码至少 8 位。每个实例只有这一个面板账号。

面板端口默认为 8088。面板只监听本机，安装在服务器上时需要通过 SSH 端口转发访问，方法见本页最后一节。

## 2. 连接 QQ

连接方式有两种。

- **LenBot 连接 OneBot**（正向 WebSocket）。填写 OneBot 地址，默认 `ws://127.0.0.1:3001`，按 OneBot 实际端口修改。两者在同一台机器上时，这种方式最简单。在 Docker 中运行时默认 `ws://host.docker.internal:3001`，指向运行 Docker 的这台机器。
- **OneBot 连接 LenBot**（反向 WebSocket）。填写 LenBot 的监听地址和端口，再在 OneBot 中把反向连接地址指向该地址。

两种方式的区别和 OneBot 一侧的设置见[接入 QQ](./onebot)。

***访问令牌**与 OneBot 中的设置一致，OneBot 未设置时留空。反向连接监听 `127.0.0.1` 以外的地址时，必须设置访问令牌。

填写完成后点击**测试连接**。LenBot 连接 OneBot 并读取当前登录的 QQ 号，成功时显示「已连接，Bot 账号 …」，测试通过后才能进入下一步。

最后选择**发送方式**，首次建议选择**模拟发送**：Bot 照常接收消息并生成回复，回复只显示在面板中。确认无误后，在**总览**的状态卡上切换为**发送到 QQ**，立即生效。

## 3. 主人与时区

填写自己的 QQ 号。主人是 Bot 权限最高的用户，可以在群内直接让 Bot 修改设置。其他主人可以之后在面板中添加。

时区默认为 `Asia/Shanghai`，提醒、安静时段和面板中显示的时间都按该时区计算。

## 4. 聊天模型

这一步配置聊天模型。看图、整理记忆、学习和后台任务默认也使用该模型，换用其他模型时在面板中配置，见[模型与用量](./models#模型用途)。

先选择 **DeepSeek**、**OpenAI 兼容**或**Anthropic 兼容**。三个入口都直接显示接口地址、Key 和模型名。DeepSeek 预填接口地址、`deepseek-flash`、思考强度和输出字段，地址可以修改；Anthropic 兼容预填官方地址、思考强度 `high` 并打开图片支持。填写连接后可以读取模型列表并按模型 ID 或名称搜索，也可以直接输入模型 ID，再按需测试模型。

***首轮请求使用低档思考（推荐）**：开启后，收到新消息后的第一次请求使用 `low` 档思考，查询资料后恢复原思考强度。DeepSeek 和 Anthropic 兼容默认开启，OpenAI 兼容默认关闭，之后可以在**模型 → 用途**的聊天模型中修改。

**搜索服务**和**读取方式**分别选择，免费和付费的都有：

| 搜索服务 | 说明 |
|---|---|
| DeepSeek | 按次收费。可以复用 DeepSeek 聊天连接，也可以单独填写连接 |
| Tavily、Brave Search、博查 | 按次收费，填写各自的 Key |
| Yahoo、Bing RSS | 免费，不需要 Key |

| 读取方式 | 说明 |
|---|---|
| 本机直接读取 | 免费，由 LenBot 自己抓取网页并提取正文 |
| DeepSeek | 按次收费，复用 DeepSeek 搜索或聊天的连接 |
| Tavily | 按次收费，和 Tavily 搜索共用一个 Key |
| Jina Reader | 按用量收费，填写 Jina 的 Key |

搜索和读取选同一家时共用一个连接，选不同服务时分别填写。DeepSeek 搜索和读取的价格见[官方说明](https://api-docs.deepseek.com/zh-cn/guides/search/)。

**更多参数**中可修改代理、上下文长度、压缩阈值、输出额度、两档思考、图片支持和每轮步数，步数默认 16。***向量模型**为可选项；未配置时本地记忆使用全文检索，之后可在**模型 → 向量模型**中添加。

## 5. 角色和第一个群

角色默认使用**小然**。选择**自定义角色**时填写名字和人物设定，说话方式和底线可选。角色文件夹名在**更多设置**中，留空时，英文名字据此生成（例如 `Mika Chan` 生成 `mika-chan`），其他名字使用 `my-bot`。

选择群聊并填写群号，或选择私聊并填写对方 QQ。在群聊中，Bot 初始只回应 @ 或回复它的消息；私聊中每条消息都会回复。其他群之后在面板中接入。

***官方插件**按需展开，勾选后在保存时安装。安装后在面板的插件页启用、修改设置并选择使用的群。安装失败时显示错误，可以重试或取消勾选。

## 保存之后

LenBot 按新配置启动，页面显示**正在启动 LenBot**，面板启动后自动跳转到登录页并填好用户名。

面板一段时间后仍未响应时，页面显示**配置已保存**和面板地址。通过 SSH 端口转发或反向代理访问时，本机端口可能不同，请把地址改为实际访问的地址后点击**打开面板**，同时查看终端输出，常见原因是面板端口已被占用。配置已经写入，问题解决后重新启动 LenBot 即可，无需重新配置。

## 之后修改设置

所有设置保存在实例目录的 `lenbot.config.json` 中，LenBot 只读取这一个文件。文件里有 API Key 和密码哈希，不要提交到 Git。

日常在面板中修改设置。部分设置需要重启生效，保存后页面顶部会提示；点击重启前，面板列出受影响的设置和进行中的工作。手动编辑该文件前请先停止 LenBot。

## 从其他机器打开面板

面板默认只监听本机，从其他机器访问时可以使用 SSH 端口转发。

```sh
ssh -L 8088:127.0.0.1:8088 你的服务器
```

然后在本地电脑上打开 `http://127.0.0.1:8088`。长期从外网访问时，请在面板前配置 HTTPS 反向代理。代理要保留 Host，并设置 `X-Forwarded-For` 和 `X-Forwarded-Proto`。代理不在 LenBot 这台机器上时，把代理的地址填进根配置的 `panel.trusted_proxies`。
