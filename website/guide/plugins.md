# 插件

插件可以为 Bot 增加命令和定时推送，也可以提供工具和技能。LenBot 不内置业务插件，以下官方插件需要单独安装和更新。

| 插件 | 功能 |
|---|---|
| [群聊总结](https://github.com/lendevs/lenbot-plugin-group-digest) | `/群日报` 把一段时间内的聊天整理成总结卡片，也可以每天定时发送。`/群总结` 生成文字总结。`/群工作` 把较长的工作交给后台任务。聊天中 Bot 也可以调用这些功能 |
| [GSUID Core 桥接](https://github.com/lendevs/lenbot-plugin-gscore-adapter) | `/gs` 把命令转发给独立运行的 GSUID Core，返回的图文由 LenBot 发送 |
| [A-SOUL 日程与动态](https://github.com/lendevs/lenbot-plugin-asoul) | `/日程` 发送日程卡片，也可以查询动态和二创并发送卡片 |
| [哔哩哔哩](https://github.com/lendevs/lenbot-plugin-bilibili) | 查询视频和搜索，推送直播和关注的更新。配置主人账号后，可以读取、点赞和收藏 |

这些插件尚未发布正式版本，安装时使用与当前 LenBot 一起测试过的提交。

## 安装

在**插件 → 发现插件**中安装。安装来源有三种。

- 从插件目录挑选
- 从 Git 仓库安装
- 导入 ZIP 文件

使用 Git 安装时，系统中需要安装 `git`。

安装分为两步。

1. **准备**。下载或解包插件，读取插件清单，检查 LenBot 版本和 Python 版本是否兼容，以及系统是否支持。
2. **应用**。填写必填参数后应用。依赖没有变化的插件会直接重新加载。依赖有变化或插件声明需要重启时，在下次重启的停机阶段安装依赖后切换。

插件安装后默认不在任何群启用。在插件详情的**使用的群**页签中点击群名，可以开启或关闭；也可以在**群聊 → 设置 → 本群启用的插件**中按群开关。修改立即生效，只重新加载该插件，聊天不中断。

插件详情有六个页签：**设置**（插件参数）、**使用的群**、**工具**和**技能**（插件提供给 Bot 的能力）、**日志与错误**、***版本**（更新、选择版本和回退到上一版本）。

## 更新和回退

- 通过 Git 安装的插件可以指定分支、标签或提交，更新时沿用原来的选择。通过 ZIP 安装的插件，更新时重新导入新版本的包。
- 新版本的参数单独保存，应用新版本时才生效。取消更新时，旧版本的参数保持不变。
- 应用新版本时保留一份旧版本的源码和参数。新版本在加载、启动或数据迁移时失败，LenBot 自动切回旧版本；新版本已修改数据时，数据同时恢复为升级前的备份。
- 在插件详情的**版本**页签中可以手动回退到上一版本一次。手动回退恢复上一版的源码和参数，插件数据沿用当前数据。
- 插件需要修改数据格式时，LenBot 先把插件数据备份到 `.backups`，再执行插件的迁移。旧版本插件无法读取新格式，启动时拒绝并说明原因。

## 权限和运行状态

插件可以在 `plugin.toml` 中声明所需权限，例如在启用的群内发送消息、读取聊天记录或调用模型。声明了权限的插件只能使用这些能力，越权操作会失败并记为插件错误；未声明权限的插件可以使用全部能力。

声明了进程隔离的插件运行在独立进程中，崩溃时只有该插件变为失败，Bot 照常聊天。查看错误后重新加载插件即可恢复。

## 停用和卸载

- 停用插件时，参数和启用的群保留。
- 卸载插件时，删除源码和配置，保留插件数据。删除数据需要单独操作。

## 依赖和兼容

插件和 LenBot 使用同一个 Python 环境。依赖发生冲突时显示原始错误。

编写插件的方法见[写插件](../develop/plugins)。
