# 在群里聊天

本页说明 Bot 在群聊中的唤醒渠道、连发消息合批、回复方式、安静控制与发言上限。

## 唤醒方式

Bot 仅在被唤醒时发起聊天模型请求；未被唤醒的群消息只写入本地记录作为后续上下文。被唤醒后，是否开口以及回复哪条消息均由聊天模型自行决定。

| 唤醒方式 | 触发条件 |
|---|---|
| 被 `@` 或回复 | 消息 `@` 了 Bot、引用回复了 Bot 的消息，或来自私聊 |
| 点名 | 消息文本中出现当前角色的名字、角色别名或本群附加称呼 |
| 持续关注 | 命中了 Bot 先前通过 `attention` 工具登记的待跟进事项 |
| 对话继续 | Bot 刚发过言，在留意窗口内收到后续消息 |
| 群内讨论 / 随机唤醒 | 开启**同时参与群内讨论**后，群内消息的参与分达到插话门槛，或命中低概率随机唤醒 |
| 提醒 / 任务 / 插件 | 定时提醒到点、后台任务完成或提问、插件主动推送场景事件 |
| 主动发起话题 | 开启后，群内静默超过设定时长（默认 3 小时）且处于每日允许时段（默认 `10:00`–`22:00`）时触发，每天最多一次 |

新接入的群聊默认将**发言时机**设为**只在被 `@`、回复或私聊时**。需要 Bot 自主参与日常话题时，在**群聊 → 设置 → 参与方式**中切换为**同时参与群内讨论**，并调整**活跃度**与**关键词**。活跃度越高，插话门槛越低。

开启**观察群友对 Bot 发言的反应**（位于**群聊 → 学习 → 学习设置**）后，宿主会根据近期主动插话后的群友反馈动态微调插话参与分：若近期插话常被无视或引起反感，参与分按系数下调（最低降至原值的 `0.7` 倍，对应更高门槛）；群友顺着话题继续讨论或表示认同时不降低。反馈权重随时间衰减，超过 3 天的记录不再计入。被 `@`、被回复、点名和对话继续不受此系数影响。

### 对话继续窗口

Bot 每次发言后会保持一段时间的留意窗口（**发言后的留意时长**），期间群内出现后续回应时无需再次 `@` 即可按**对话继续**唤醒。

当某次由**对话继续**唤醒的回合被模型判定为无需接话（保持沉默旁听）时，留意窗口随即提前结束，后续普通消息恢复按常规参与分判断，避免他人已转向别的话题时反复唤醒。该行为由**群聊 → 设置 → 参与方式 → 等待与插话参数**中的**对话继续阶段选择沉默时结束留意**开关控制（默认开启）。

## 连发合批与回复方式

### 连发消息合批

群友习惯把一句话拆成几条短消息或先发图再补文字。Bot 被唤醒后不会立刻请求模型，而是先等待一小段空闲时间将连续到达的消息合并进同一回合：

- **已发言人续发顺延**：本批等待期间已经发过言的群友再次发送消息时，空闲计时顺延（即使中间夹着其他群友插话也同样顺延）；本批首次出现的新发言人发消息不重新计时。
- **纯图片延长等待**：若当前最后一条消息仅包含图片，且发图人本批已发过言（或该图片本身就是唤醒消息），空闲等待时间加倍，留出补充说明文字的时间。
- **总时长封顶**：每种唤醒渠道均设有最长等待秒数（例如**被叫到后的最长等待秒数**默认为 4 秒），达到上限后立即进入回合。进入回合后，若模型判断对方仍在输入，也可调用 `wait` 工具再等待数秒读取新消息。

### 回复形式

聊天模型在同一回合内可选择以下任意组合：

- **文字发言（`say`）**：发送一条或多条消息，支持引用目标消息或 `@` 指定群友。单条文本超过字数上限（默认 300 字）时在换行或句末自动分段，并按配置的打字速度控制分条间隔。
- **发送表情（`react`）**：单独发送角色表情或本群收集的表情图片，或在调用 `say` 时将文字与表情合成为同一条消息发出。当同一情绪下有多张相近候选、仅凭文字描述难以区分画面细节时，支持看图的聊天模型可先预览最多 9 张带编号的候选缩略拼图，再按编号发送；发送副本最长边自动缩放至 320 像素并保留动图帧，角色包原图不变。
- **贴表情回应（`message_reaction`）**：调用 QQ 群消息贴表情接口，为某条群消息贴一个简短表情回应而不发出新气泡。
- **旁听不发言**：不调用任何对外表达工具（或显式结束回合），继续保持安静。

同一回合内若连续两次发送出现 `发送失败`、`发送状态未知` 或部分送达，该回合立即以 `发送失败` 状态终止，不再继续后续发送步骤。

## 收集群内表情

在**群聊 → 学习 → 学习设置**中开启**收集群内表情**后，宿主会自动跳过平台标记为普通照片或截图的图片，仅使用看图模型为表情包生成画面描述、图中文字、情绪和适用标签。

同一群内重复出现的相同图片复用已有标注与审核状态。新识别的表情进入**待审核**列表，按群内发送频次优先排列并展示发送次数与人数；在**群聊 → 学习 → 表情**中点击**采用**后即可供 Bot 在该群发送。各群收集的表情库相互独立。

## 首轮请求低档思考

开启**首轮请求使用低档思考（推荐）**（位于**模型 → 用途 → 聊天**）后，回合第一步请求使用 `low` 档思考强度快速给出直接回复或工具调用；若第一步调用了查询工具，同一回合后续读取工具结果的请求自动恢复主思考强度。

## 安静时段与临时安静

- **每日安静时段**：在**群聊 → 设置 → 每日安静时段**中设定起止时间（支持跨零点，例如 `23:00` 至 `08:00`）。安静时段内 Bot 不主动插话或发起话题；期间被 `@` 时的行为可选**照常回复**、**回复固定内容**或**安静时段结束后回复**。
- **临时安静**：在群聊工作台右上角 **…** 菜单点击**临时安静**，或由有权限的成员在群内发送 `/quiet <分钟>`（最长 7 天），也可由模型应群友要求调用 `scene_control` 工具进入临时安静。

## 每小时发言上限

LenBot 按滑动 60 分钟窗口统计每个群的发言次数，全局默认上限为每群每小时 60 条（在**系统 → 设置 → 群聊**中修改）；单群可在**群聊 → 设置 → 每小时发言上限**中选择**跟随全局**、**自定义**或**不限**。私聊不设每小时发言上限。

计入上限的规则：

- 每次成功送达（含模拟发送）的 `say`（无论自动拆分为几段或是否附带表情）、`react` 单独发表情，以及 `/help`、`/id` 命令回复，各计 1 条。
- `message_reaction`（给消息贴表情）、管理员维护命令回复、每日安静时段的固定提示语，以及插件自行发出的消息均不计入上限。

常规额度用尽后，Bot 停止主动插话和发起话题；被 `@`、被回复、到点提醒和后台任务结果可使用额外余量（**用完后被 `@` 时的额外条数**，默认 5 条）。余量也耗尽后该群暂停发言，待滑动窗口内最早的发言滑出 60 分钟后自动恢复，期间积累的未读消息保留至恢复后处理。

可在**系统 → 设置 → 群聊**中开启**全部用完后被 `@` 时回复固定内容**（每次限流周期最多提示一次）。达到上限的群会出现在**总览**的待处理事项中，也可在群设置页点击**本小时临时放开**立即清零当前窗口计数。

## 群聊开关、全部暂停与模拟发送

- **单群聊天开关**：位于**总览**群列表与群聊工作台右上角。关闭后平台消息继续记入数据库，但 Bot 不唤醒，插件也不在该群响应命令或推送；重新打开后仅处理新到达的消息。
- **全部暂停 / 全部恢复**：位于**总览**顶部状态卡，一键暂停或恢复所有已接入群聊。
- **模拟发送切换**：位于**总览**顶部状态卡，可随时在**发送到 QQ** 与**模拟发送**间实时切换，模拟期间产生的发言同样计入每小时发言上限，切回真实发送后不会补发模拟期间的消息。若仅需固定将个别群设为模拟发送，可在停机后将该群配置中的 `"simulated_delivery"` 设为 `true`。
- **每日 token 上限**：按全实例合计或按单群限制每日模型 token 消耗，详见[模型与用量](./models#用量与上限)。
