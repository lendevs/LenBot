# 在群里聊天

本页说明 Bot 在群内的发言时机、发言量和临时安静的方法。

## 唤醒方式

Bot 只在被唤醒时调用模型。唤醒后，是否回复、回复哪一条由模型判断。

| 方式 | 触发条件 |
|---|---|
| 被叫到 | 被 @、被回复，或私聊中的每条消息 |
| 点名 | 消息中出现角色的名字或别名 |
| 对话继续 | Bot 刚说完话，对方接着回应 |
| 参与群聊 | 开启参与群聊后，群内讨论的参与分超过门槛 |
| 提醒和任务 | 到点的提醒、后台任务的结果、插件推来的事件 |
| 主动开话题 | 开启后，群内无人发言超过设定时长（默认 3 小时）时触发，每天最多一次，默认只在 10:00 到 22:00 之间 |

新接入的群默认只回应被叫到和回复 Bot 的消息。需要 Bot 参与讨论时，在**群聊 → 设置 → 参与方式**中把**发言时机**改为**同时参与群内讨论**，再调整活跃度。活跃度越高，越容易超过门槛。

**群聊 → 现场**中每条群友消息的时间后有一个图标：闪电表示这条消息唤醒了 Bot，月亮表示没有。点开可以看到唤醒方式、参与分和门槛。

### 对话继续

Bot 发言后继续留意一段时间，期间对方回应时直接唤醒。一次因对话继续被唤醒的回合选择不回复后，后续的普通消息改由参与分决定是否唤醒。被 @、被回复和点名不受影响，Bot 下次发言后重新开始留意。

这一行为由**群聊 → 设置 → 参与方式 → 等待与插话参数**中的**对话继续阶段选择沉默时结束留意**控制，默认开启。

## 回复方式

模型可以选择以下任一种方式，也可以组合使用：

- 发送一条或多条文字消息。超过长度上限（默认 300 字）的内容在换行或句末处拆开，按打字速度间隔发送
- 引用原消息，或 @ 群友
- 发送表情包，或把文字和表情合成一条消息
- 只给消息贴一个表情
- 不回复，继续旁听

对方连续发送多条消息时，模型可以先等待几秒，读完后再回复。

## 首轮请求使用低档思考

收到新消息后的第一次模型请求使用较低的思考强度，查询资料后再使用原来的强度，以缩短回复时间。在首次配置的聊天模型步骤或**模型 → 用途 → 聊天**中开关，DeepSeek 和原生协议默认开启。

## 安静时段与临时安静

- **安静时段**：在**群聊 → 设置 → 安静时段**中设置每天的时间段。期间 Bot 不主动发言。被 @ 时可以照常回复、回复固定内容，或延后到安静时段结束再回复（默认）。
- **临时安静**：在群聊工作台的 **…** 菜单中选择**临时安静**，或由管理员在群内发送 `/quiet <分钟>`，最长 7 天。

## 每小时发言上限

LenBot 统计每个群最近 60 分钟内的发言次数，默认每群每小时 60 条。全局默认值在**系统 → 设置 → 群聊**中修改；单个群在**群聊 → 设置 → 每小时发言上限**中选择跟随全局、自定义或不限。私聊不受限制。

计数规则：

- 一次发言计一条。拆成多条发送、文字附带表情，都只计一条。单独发送表情计一条，给消息贴表情不计。
- 插件发送的内容不计数，也不受上限限制。
- 安静时段的固定回复不计数。

达到上限后，Bot 不再主动插话或开话题。被 @、被回复、到点的提醒和后台任务结果可以继续使用一份余量，默认 5 条，在**系统 → 设置 → 群聊**中修改。余量也用完后，该群暂停发言，直到最早的一次发言超过 60 分钟。暂停期间的未读消息会保留，恢复后一并处理。

接近上限时，Bot 在回复前能看到本群剩余的条数。需要在暂停期间提示群友时，开启**全部用完后被 @ 时回复固定内容**并填写内容，每次暂停最多发送一次。

达到上限的群会出现在总览的待处理事项中，点击**本小时临时放开**可以清零计数。上限的修改保存后立即生效。

## 群聊开关与全部暂停

- **群聊开关**：位于总览群列表和群聊工作台右上角。关闭后，消息照常记录，Bot 不回复、不主动发言，插件也不在该群响应。重新打开后从新消息开始处理，不补回关闭期间的消息。
- **全部暂停**：位于总览顶部的状态卡。一次关闭所有群的聊天开关，适合模型额度用完时使用。全部关闭后按钮变为**全部恢复**。

## 模拟发送

真实发送到 QQ 时，总览状态卡上有**发送到 QQ**和**模拟发送**两个选项。切换到模拟发送后，Bot 照常回复，但回复只记录在面板中，贴表情也只记录。模拟的发言同样计入发言上限。该状态在重启后保持；切回**发送到 QQ**后，之前模拟的内容不会补发。

这个选项用于临时切换。长期修改发送方式在**系统 → 设置 → 连接**的**发送方式**中进行。只需要部分群不发言时，可以在配置文件中为这些群设置 `"simulated_delivery": true`，重启后生效。

## 用量与上限

**模型 → 用量与上限**中显示今天和本月的 token 用量，可以设置每天的 token 上限，详见[模型与用量](./models#用量与上限)。
