# 接入 QQ（OneBot）

LenBot 本身不登录 QQ。它连接一个已经登录 QQ 并开启了 OneBot v11 WebSocket 的程序，例如 [NapCat](https://github.com/NapNeko/NapCatQQ)，通过这个程序收发消息。这类程序的安装和登录方法见其各自的文档。

## 选择连接方式

| 方式 | 连接方向 | LenBot 一侧填写 | OneBot 一侧开启 |
|---|---|---|---|
| 正向 WebSocket | LenBot 连接 OneBot | OneBot 的地址，例如 `ws://127.0.0.1:3001` | WebSocket 服务端 |
| 反向 WebSocket | OneBot 连接 LenBot | 监听地址和端口，向导默认 `127.0.0.1:8080` | WebSocket 客户端，地址填 `ws://<LenBot 地址>:<端口>` |

两者在同一台机器上时，两种方式都可以使用，正向连接更简单。OneBot 在另一台机器或另一个容器里时，按网络的可达方向选择。LenBot 能访问 OneBot 时使用正向连接，反之使用反向连接。

**访问令牌**在两侧填写相同的值。反向 WebSocket 监听本机以外的地址时（例如 `0.0.0.0`），必须设置访问令牌。

使用反向连接时，OneBot 一侧需要满足以下三个条件，否则 LenBot 会拒绝连接。

- 使用 Universal 模式，在同一条连接上接收事件和调用接口。
- 同一时间只建立一条连接。
- 登录的 QQ 号与配置中的 Bot 账号一致。

首次配置时点击**测试连接**，显示「已连接，Bot 账号 …」即连接成功。之后在面板的**系统 → 设置 → 连接**中修改连接方式。连接状态显示在总览和顶栏。

## 消息格式与自发消息

OneBot 一侧的消息上报格式选择 **array（数组）**，例如 NapCat 的 `messagePostFormat` 设为 `array`。

需要记录 Bot 账号在其他设备上发出的消息时，在 OneBot 中开启自发消息上报（NapCat 的 `reportSelfMessage`）。LenBot 接收 `message_sent`，按平台消息 ID 合并自己发出的回显。手动发送的自身消息进入对应群聊或私聊的上下文。

## 断线处理

运行期间连接断开时自动恢复。

- **正向连接**。LenBot 自动重连。第一次等待 1 秒，之后每次等待时间翻倍，最长 30 秒。连接恢复并稳定 30 秒后，下次断线重新从 1 秒开始计算。重连后再次核对 QQ 号。重连失败的原因和下次重试的间隔显示在总览，并以**平台连接出错**事件写入**系统 → 日志**。
- **反向连接**。LenBot 持续监听，等待 OneBot 重新连接。

以下两种情况需要手动处理。

- **启动时首次连接失败**，例如地址填错或 OneBot 尚未启动。检查地址和 OneBot 状态，问题解决后点击总览上的**手动连接 QQ**。
- **在总览上点击了断开 QQ**。在右上角账号菜单中重启后才会重新连接。

## 模拟发送和真实发送

- **模拟发送**。Bot 照常接收消息并生成回复，回复只记录在面板中，不发送到 QQ。刚安装时可以用这种方式观察效果。
- **真实发送到 QQ**。角色和设置确认后，在**系统 → 设置 → 连接**的**发送方式**中切换，重启后生效。

## OneBot 运行在容器中

OneBot 运行在 Docker 容器中、LenBot 运行在宿主机上时：

- 使用正向连接，需要把 OneBot 的 WebSocket 端口发布到宿主机，LenBot 填写 `ws://127.0.0.1:<发布的端口>`。
- 使用反向连接，容器内的 `127.0.0.1` 指向容器本身，OneBot 一侧需要填写宿主机在 Docker 网络中的地址，LenBot 的监听地址也要改为该网络可以访问的地址，并设置访问令牌。

## 发送文件

后台任务生成的文件要发送到 QQ 时，OneBot 必须能读取 LenBot 的交付目录。设置方法分两步。

1. 把交付目录以只读方式挂载给 OneBot。
2. 在**系统 → 设置 → 连接 → 更多设置**中填写**OneBot 可见的文件目录**（配置项 `onebot.upload_visible_root`），值为 OneBot 一侧看到的绝对路径。

详见[后台任务](./tasks#发送到-qq)。

## 分享卡片

QQ 小程序、图文和音乐分享卡片的提示、标题和简介会提供给 Bot，每项最多 80 字，不包含图标和跳转链接。卡片没有文字或内部 JSON 无法解析时显示为 `[json]`。
