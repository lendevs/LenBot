# 角色

角色规定 Bot 的身份和说话方式。每个角色是一个目录，只有 `persona.yaml` 是必需的，填写 `name` 和 `brief` 即可使用，其他文件按需添加。

| 文件 | 内容 |
|---|---|
| `persona.yaml` | 名字、身份、性格、别名、工具和技能许可（必需） |
| `voice.md` | 说话方式 |
| `boundaries.md` | 底线 |
| `examples.yaml` | 人工编写的情境和台词 |
| `knowledge/` | 按需检索的资料 |
| `stickers/` | 表情图片和 `index.yaml` |
| `response_choice.md`、`expression_principles.md`、`chat_examples.md` | 角色自定义的回应判断、一般说法和情境示范，缺省时使用框架版本 |

Bot 可以单独发表情，也可以把文字和表情合成一条消息。需要同时说话和配图时，优先使用组合发送。表情的发送副本最长边为 320 像素，保留比例和动画；角色包里的原图不改。

首次配置时会创建第一个角色。面板的**角色**页列出实例中的全部角色，包括未被群使用的角色。

- 可以新建空白角色、复制已有角色或导入 ZIP，导入和复制都会新建角色目录。角色卡片的菜单中可以导出 ZIP；未被群使用的角色可以删除，文件夹移至 `.runtime/deleted-personas`。
- 修改后可以先在**效果**页签试聊或查看提示词预览，两者都使用设定和说话页签中尚未保存的修改，确认后再保存。
- 保存后立即生效，正在回复的群在本轮回复结束后应用。

角色详情包含以下页签。

| 页签 | 内容 |
|---|---|
| 设定 | 头像、名字、简介、底线；别名、自称和做事方式在**更多设置**中 |
| 说话 | 说话方式和样例；说话风格和样例筛选在**更多设置**中 |
| 效果 | **对话试聊**：用当前设定在所选群的环境中试聊，试聊开始后再修改设定时显示**草稿已变更**，可以用当前草稿重新开始。**提示词预览**：按所选群显示角色进入系统提示词的内容，包括角色材料（含该群的称呼、关系、额外要求和选中的样例）、三份表达规则及其来源，以及说话风格的比例和一次抽取结果。资料、工具与技能、文件页签中未保存的修改不参与试聊和预览 |
| 资料 | 按需检索的资料文件 |
| 表情 | 表情图片和标签 |
| 工具与技能 | 角色可以使用的工具和技能 |
| 群 | 使用该角色的群 |
| 文件 | 直接编辑 `persona.yaml`、`voice.md`、`boundaries.md`、`examples.yaml` 的原文，以及三份表达规则；表达规则为空时显示框架内容，可以填入后修改，清空保存即恢复框架版本 |

## 给群换角色

每个群同一时间只使用一个角色。切换方式有三种，均立即生效，无需重启：

- 在角色页打开角色，点击**应用到群**，可以一次选择多个群。
- 在群聊工作台顶部点击角色名，或在**群聊 → 设置 → 角色**中选择。
- 主人或全局管理员在群内发送 `/角色 名字`，切换完成后 Bot 回复「已切换为 名字」。名字可以是角色名、别名或目录名。只发送 `/角色` 时列出当前角色和可切换的角色。其他群友发送这条命令时按普通聊天处理。

切换角色时：

- 群友资料、群内事件和群画像由所有角色共用，新角色同样了解群内成员。
- Bot 自身的记录（发言、承诺）按角色分开存放，召回时只读取当前角色的记录。切回原角色后，其记录恢复可用。
- 当前聊天上下文整理为一份交接，写明此前各角色的发言和承诺，新角色基于这份交接继续对话。整理交接调用一次模型。
- **群聊 → 设置 → 本群的称呼与额外要求**中的三项（群友对 Bot 的其他称呼、与群友的关系、本群的额外要求）按角色保存，切换时收起，切回时自动恢复。新角色首次用于该群时这三项为空。
- 上一个角色创建的提醒和任务照常执行，由当前角色完成。

角色文件的写法和样例见[写角色包](../develop/personas)，也可以参考仓库中的[示例角色](https://github.com/lendevs/LenBot/tree/master/examples/personas/companion)。
