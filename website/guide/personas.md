# 角色

角色规定了 Bot 的身份和说话方式。每个角色是一个目录，只有 `persona.yaml` 是必需的，里面写上 `name` 和 `brief` 就能用。其他文件按需添加。

| 文件 | 内容 |
|---|---|
| `persona.yaml` | 名字、身份、性格、别名、工具和技能许可（必需） |
| `voice.md` | 说话方式 |
| `boundaries.md` | 底线 |
| `examples.yaml` | 人工编写的情境和台词 |
| `knowledge/` | 按需检索的资料 |
| `stickers/` | 表情图片和 `index.yaml` |
| `response_choice.md`、`expression_principles.md`、`chat_examples.md` | 这个角色自己的回应判断、一般说法和情境示范，不放时用框架的版本 |

Bot 可以单独发表情，也可以把文字和表情合成一条消息。需要同时说话和配图时，优先使用组合发送。表情的发送副本最长边为 320 像素，保留比例和动画；角色包里的原图不改。

首次配置时会创建第一个角色。面板的**角色**页列出实例里的全部角色，包括还没有群在用的。

- 可以新建空白角色、复制已有角色，或者导入 ZIP。导入和复制都会新建一个角色目录。角色卡片的菜单里可以导出 ZIP；没有群在用的角色可以删除，文件夹移到 `.runtime/deleted-personas`。
- 修改后，可以先在**试聊**页签试聊。试聊使用尚未保存的设定，确认满意后再保存。
- 保存后立即生效。正在回复的群会等这一轮回复结束后再用上新内容。

打开一个角色后有这些页签。

| 页签 | 内容 |
|---|---|
| 设定 | 头像、名字、简介、底线；别名、自称和做事方式在**更多设置**里 |
| 说话 | 说话方式和样例；说话风格和样例筛选在**更多设置**里 |
| 预览 | 选一个群，看这个角色拼进系统提示词的内容：角色材料（含这个群的称呼、关系和额外要求，以及选中的样例）、三份表达规则及其来源，以及说话风格的比例和一次抽取结果 |
| 资料 | 按需检索的资料文件 |
| 表情 | 表情图片和标签 |
| 工具与技能 | 这个角色可以使用的工具和技能 |
| 群 | 哪些群在用这个角色 |
| 试聊 | 用尚未保存的设定在某个群的环境里试聊 |
| 文件 | 直接编辑 `persona.yaml`、`voice.md`、`boundaries.md`、`examples.yaml` 的原文，以及三份表达规则；表达规则空白时显示框架的内容，可以填入后再改，清空保存就回到框架版本 |

## 给群换角色

每个群同一时间只用一个角色，有三种换法，都会立即生效，不用重启：

- 在角色页打开一个角色，点**用到群**，一次可以选多个群。
- 在群聊工作台顶部点角色名，或者在**群聊 → 设置 → 角色**中选择。
- 机器人主人或全局管理员在群里发 `/角色 名字`，Bot 换好后回一句「已换成 名字」。名字可以写角色名、别名或目录名。只发 `/角色` 会列出现在的角色和可以换的角色。其他群友发这条命令，当普通聊天处理。

换角色时：

- 群友资料、群里发生的事和群画像所有角色共用，新角色也认识群里的人。
- Bot 自己的记录（说过的话、答应的事）按角色分开存放，召回时只看当前角色自己的。换回原来的角色后，它的记录会回来。
- 当前的聊天上下文会整理成一份交接，写明之前是哪个角色说了什么、答应了什么。新角色从这份交接接着聊。整理交接需要调用一次模型。
- **群聊 → 设置 → 本群的称呼与额外要求**里的三项（群友对 Bot 的其他称呼、和群友的关系、本群的额外要求）是给某个角色写的，换走时会收起来，换回来时自动恢复。新角色第一次来到这个群时这几项是空的。
- 上一个角色设下的提醒和任务照常执行，由当前角色完成。

角色文件的写法和样例见[写角色包](../develop/personas)，也可以参考仓库里的[示例角色](https://github.com/lendevs/LenBot/tree/master/examples/personas/companion)。
