# 可选服务

只用于聊天时，有 OneBot 和一个聊天模型就足够了。下面这些服务按需添加，都在面板里配置。

## 模型用途

只配置聊天模型就能用全部功能：看图、记忆摘要和后台任务都可以使用聊天模型。整理记忆和学习固定由聊天模型接着聊天会话完成，可以复用服务商的缓存。想让某种用途换一个模型时，到**模型 → 用途**中打开它，再选择服务商和模型。

| 用途 | 配置中的名称 | 作用 | 没有单独配置时 |
|---|---|---|---|
| 聊天 | `mind` | 判断是否回复，决定回复的内容和使用的工具 | 必需 |
| 看图 | `vision` | 理解群里发送的图片 | 聊天模型直接看图；聊天模型的**能看图**关闭时不能看图 |
| 记忆摘要 | `memory` | 编写记忆目录摘要 | 使用聊天模型 |
| 插件生成 | `learner` | 插件的单次文字生成 | 使用聊天模型 |
| 后台任务 | `worker` | 后台任务使用的模型 | 使用聊天模型 |
| 语音转写 | `asr` | 把语音转写成文字 | 不转写 |

单独配置看图模型时，由它把图片写成文字描述交给聊天模型；没有配置时，聊天模型在这一轮里直接看原图。

上下文窗口、输出上限和超时时间按服务商的文档填写。模型拒绝请求时会直接报错，LenBot 不会自动缩小参数，也不会换用其他模型重试。

## 向量检索

记忆默认使用全文检索。如果需要按语义检索，需要准备一个 OpenAI 兼容的 embeddings 服务。使用 Ollama 时，可以执行下面的命令。

首次配置的「向量模型」步骤可以跳过，也可以使用聊天服务商的向量接口或填写独立的向量服务商。跳过时启用本地记忆并使用全文检索。

```sh
docker compose -f deploy/current/services.compose.yaml up -d embeddings
docker exec lenbot-embeddings ollama pull bge-m3:567m
```

然后在面板中添加 `openai-embeddings` 服务商，地址填 `http://127.0.0.1:11434/v1`。在**模型 → 向量模型**中开启记忆向量，选择服务商，模型填 `bge-m3:567m`，维度填 1024。可以读取列表并选择完整模型 ID，也可以手动填写；「测试向量接口」会显示实际返回的维数。

各群开启学习后，也可以在同一页分别配置学习向量。更换地址、模型或维数后，已有索引需要停止 LenBot 并[重建](./memory#重建索引)。重启不会自动重建，仅修改服务商名称无需重建。

## 语音转写

自动转写群里的语音需要一个 OpenAI 兼容的转写服务。设置分两步。

1. 在**模型 → 用途**中打开**语音转写**，选择这个服务。
2. 在**群聊 → 设置 → 参与方式**中打开**自动转写语音消息**。

在本地部署 whisper.cpp 的方法见仓库里的 [ASR 说明](https://github.com/lendevs/LenBot/blob/master/deploy/current/asr.md)。

## 账号浏览

让后台任务使用自己已登录的浏览器时，需要以下三样东西，见[浏览器配套组件](https://github.com/lendevs/LenBot/blob/master/deploy/browser/README.md)。

- 单独运行的守护进程
- 浏览器扩展
- 两者之间的配对

浏览普通的公开网页不需要这些，任务镜像本身就支持。

## 代理软件的 fake-ip 模式

Clash 和 Surge 等代理软件开启 fake-ip 后，所有域名都会解析成 `198.18.x.x` 这类保留地址。LenBot 在读取网页和获取图片时会拒绝保留地址，任务访问外网时也一样，报错中会出现 `私有或保留地址`。

解决方法是在**能力 → 网页**的**代理的假 IP 网段**中填写代理实际使用的网段。它对应配置文件中的以下内容。

```json
"network": {
  "fake_ip_networks": ["198.18.0.0/15"],
  "public_dns_url": "https://dns.google/resolve"
}
```

设置后，按域名连接时，如果解析结果落在这个网段内，LenBot 会通过 `public_dns_url` 查询真实的 A／AAAA 记录。确认是公网地址后，LenBot 直接连接这个地址。

- `public_dns_url` 必须是 DNS JSON 接口，接受 `name` 和 `type` 参数，返回 `Status` 和 `Answer`。无法访问 Google 时，可以换成使用同一协议的其他服务。
- 查询失败，或者查到的真实地址是内网地址时，这次请求直接报错。
- 直接写成保留 IP 的地址仍然会被拒绝。
