# 快速开始

本页说明从获取源码到 Bot 在群里回复的完整步骤。

::: tip 开发中
LenBot 尚未发布版本，目前只能从源码运行。
:::

## 准备

- [uv](https://docs.astral.sh/uv/)，用于管理 Python 和依赖。
- [Node.js](https://nodejs.org/) 22 或更新版本，用于构建网页面板。
- 一个已登录 QQ 并开启 WebSocket 的 OneBot 实现，例如 [NapCat](https://github.com/NapNeko/NapCatQQ)。首次配置时需要连接它读取 Bot 的 QQ 号，请先启动。连接方法见[接入 QQ](./onebot)。
- 模型服务的 API Key。使用 DeepSeek 时只需要 Key，其他服务还需要接口地址和模型名。

## 1. 安装并启动

```sh
git clone https://github.com/lendevs/LenBot.git
cd LenBot
./scripts/install.sh      # 安装依赖并构建面板
uv run --no-sync len-bot  # 启动
```

每次启动时，LenBot 检查面板的前端代码，有变化时自动重新构建。拉取更新后按[更新与备份](./maintenance#更新代码)操作。

从源码运行时，仓库根目录就是实例目录。配置、数据库、角色和记忆都保存在这里，均已写入 `.gitignore`。

## 2. 打开首次配置

首次启动时没有配置文件，终端输出一个链接：

```text
尚无根配置。请打开 http://127.0.0.1:52811/#token=...
```

在本机桌面环境的终端中启动时，浏览器自动打开该链接；在容器中、通过 SSH 或作为后台服务启动时，在同一台机器的浏览器中手动打开。端口每次启动随机分配，`token` 只在本次启动有效。

LenBot 安装在远程服务器上时，先在本地电脑建立 SSH 端口转发，再在本地浏览器中打开同一个链接：

```sh
ssh -L 52811:127.0.0.1:52811 你的服务器
```

## 3. 填写向导

向导共五步，各项说明见[首次配置](./first-setup)。首次使用可按以下方式填写：

1. **管理员账号**：登录面板使用的用户名和密码。
2. **连接 QQ**：确认 OneBot 地址（默认 `ws://127.0.0.1:3001`），点击**测试连接**，显示「已连接，Bot 账号 …」即为成功。发送方式选择**模拟发送**。
3. **主人与时区**：填写自己的 QQ 号，时区保留 `Asia/Shanghai`。
4. **聊天模型**：选择 DeepSeek 时只需填写 Key，搜索和读取网页保留默认。其他服务填写接口地址、Key 和模型名，可以点击**测试模型**确认模型正常回复。
5. **角色和第一个群**：角色使用默认的小然，填写一个群号。

保存后，LenBot 按新配置启动，页面自动跳转到面板登录页并填好用户名，输入密码即可登录。

## 4. 在面板中试聊

登录面板后打开**对话测试**，设置来源选择**使用群聊设置**，选择刚才填写的群，点击**开始测试**。

群聊默认只回应 @，因此先点击输入框左侧的 **@** 选中小然，再以群友身份发送消息。试聊的回复只显示在页面上。

## 5. 在群里启用

1. 在**总览**的状态卡上把**模拟发送**切换为**发送到 QQ**，立即生效，不需要重启。
2. 在群内 @ Bot，确认可以收到回复。
3. 需要 Bot 主动参与时，在**群聊 → 设置 → 参与方式**中把**发言时机**改为**同时参与群内讨论**，再调整活跃度。
