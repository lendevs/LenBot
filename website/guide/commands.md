# 群内命令

以 `/` 开头的命令由 LenBot 直接处理，不经过模型。命令前可以带引用或 @ Bot。命令消息照常记录，Bot 之后能看到谁使用过什么命令。

## 命令列表

| 命令 | 可用者 | 作用 |
|---|---|---|
| `/help` | 所有人 | 列出发送者可以使用的命令 |
| `/id` | 所有人 | 显示本群、自己和 Bot 的账号，填写权限时使用 |
| `/status` | 本群聊天管理 | 聊天开关、安静状态、最近一小时发言数、主脑模型 |
| `/chat on`、`/chat off` | 主人和全局管理员，可选群主和群管理员 | 打开或关闭本群聊天。关闭期间消息照常记录，打开后只作为背景 |
| `/quiet <分钟>`、`/quiet <分钟> defer` | 本群聊天管理 | 本群临时安静，最长 7 天。默认被 @ 或回复时仍回应，加 `defer` 后延后回应 |
| `/resume` | 本群聊天管理 | 提前结束临时安静 |
| `/reset` | 主人和全局管理员，可选群主和群管理员 | 开始新的对话上下文，聊天记录和记忆都保留 |
| `/model` | 主人和全局管理员 | 查看主脑使用的服务商和模型 |
| `/limit`、`/limit <条数>`、`/limit off`、`/limit global`、`/limit reset` | 主人和全局管理员 | 查看本群发言余量；设置本群每小时条数、不限或跟随全局；清空本群最近一小时的计数 |
| `/角色`、`/角色 <名字>` | 主人和全局管理员 | 列出当前角色和可用角色；切换到指定角色，名字可以是角色名、别名或目录名 |

## 权限

**本群聊天管理**默认包括主人、全局管理员、群主和群管理员，在**群聊 → 设置 → 权限**的**在群内让 Bot 临时安静**一行中修改。这一项只影响 `/status`、`/quiet` 和 `/resume`。

`/chat` 和 `/reset` 的效果不会自动过期，默认只有主人和全局管理员可以使用。根配置中 `commands.group_managers_chat_reset` 设为 `true` 后，群主和群管理员也可以在本群使用。

没有权限的人发送命令时，该消息按普通消息交给 Bot。黑名单中的账号不能使用命令。

## 计数规则

`/help` 和 `/id` 的回复计入每小时发言上限（不占用被叫到时的余量），本群发言用完后不再回复；同一个人 30 秒内重复发送同一条命令只回复一次。其余命令的回复不计入上限，因此发言用完时管理员仍然可以使用 `/quiet` 等命令。

## 关闭命令

插件注册了同名命令时由插件处理。在根配置中可以关闭命令：

```json
"commands": { "enabled": true, "disabled": ["limit"], "group_managers_chat_reset": false }
```

`enabled` 为 `false` 时关闭全部命令，`disabled` 列出单独关闭的命令名（不带 `/`）。修改后重启生效。

## 在群内修改设置

角色的工具许可包含 `host_manage` 和 `tool_search` 时，主人和全局管理员可以在群内用自然语言让 Bot 修改设置，例如「把本群改成只回应 @」或「改完重启一下」。群管理员没有这项权限。

可以修改的设置：

- 各群的聊天开关，以及聊天和学习参数
- 提醒、任务和角色绑定
- 网页和记忆参数
- 模型的生成参数和预算
- 数据保留
- 已安装插件的启用和停用、普通参数和启用的群

密钥、身份授权、连接方式和需要停机转换的设置不能在群内修改。Bot 默认只保存修改，只有明确要求时才重启。

权限按请求消息判断：Bot 调用管理类工具时必须指明请求消息，宿主读取该消息的发送者，不接受 Bot 自行填写的账号。
