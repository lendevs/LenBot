# 认识 LenBot

LenBot 是一个自主决策的群聊 Agent。何时开口、回复谁、先查什么、何时跟进，由模型在多步工具循环中决定。

LenBot 通过一个已登录 QQ 的 OneBot 实现收发消息。回复由用户自行准备的模型服务生成，只需要一个聊天模型和它的 API Key，例如 DeepSeek。

与 Bot 对话不需要输入命令。群友 @ Bot、回复 Bot 或提到它的名字时，Bot 读取最近的聊天后决定如何回复。开启参与群聊后，Bot 也会在群内讨论活跃时主动发言。

## 功能

| 功能 | 说明 | 详见 |
|---|---|---|
| 群聊 | 每个群保持一段连续的对话，较早的内容整理为摘要。回复可以引用原消息、@ 群友、分多条发送，或只发送表情 | [在群里聊天](./chatting) |
| 联网查证 | 搜索网页、读取正文、查询聊天记录、识别图片、读取合并转发，也可以接入 MCP 服务 | [联网与工具](./web) |
| 角色 | 名字、设定、说话方式、底线、样例、资料和表情保存在角色包中，每个群可以使用不同的角色 | [角色](./personas) |
| 记忆与学习 | 记忆以 Markdown 文件保存在本地。群内空闲时整理记忆，并学习群内的说法、黑话和回复效果 | [记忆与学习](./memory) |
| 资料检索 | 上传文件或从 QQ 群文件中选择，Bot 回答时查原文并给出文件名和位置，各群资料互不可见 | [资料检索](./reference) |
| 插件 | 用 Python 编写，可以添加命令、定时推送和模型工具 | [插件](./plugins) |
| 后台任务 | 编写报告、制作网页等耗时工作在 Docker 容器中执行，完成后把文件发送到群里 | [后台任务](./tasks) |
| 网页面板 | 首次配置、日常设置、试聊和日志都在面板中完成，每一轮回复的经过实时显示 | [面板一览](./panel) |

## 运行条件

- **一台长期运行的机器**。支持 Linux、macOS 和 Windows。
- **一个 OneBot 实现**，例如 [NapCat](https://github.com/NapNeko/NapCatQQ)。需要已登录 Bot 的 QQ 号并开启 WebSocket。
- **一个模型服务**。支持 OpenAI 兼容接口、OpenAI Responses、Anthropic 和 Gemini 四种协议。

向量检索、语音转写、付费搜索和 Docker 都是可选的，需要时再配置。

## 术语

**实例目录**
: 保存一个 Bot 全部配置和数据的目录。从源码运行时即仓库根目录。运行配置只有一个文件 `lenbot.config.json`。

**场景**
: 一个群或一段私聊。账号和场景都带平台前缀：群写作 `onebot:group:80001`，私聊写作 `onebot:private:70001`，账号写作 `onebot:70001`。

**主人**
: 权限最高的用户，可以在群里直接让 Bot 修改设置。首次配置时填写，之后可以在面板中添加。

**模拟发送**
: Bot 照常接收消息并生成回复，但回复只记录在面板中，不发送到群里。适合首次安装后观察效果。

**回合**
: Bot 被唤醒后的一次完整处理，包括召回记忆、调用模型和工具，以及发出的消息。面板中每个回合显示为一张可展开的卡片。

**回想**
: 对话变长后，较早的内容整理成的摘要。Bot 每一轮都能看到回想。

## 限制

- 目前只支持 QQ。
- 配置语音转写后可以理解语音消息，但只用文字回复。
- 提示词只有中文，面板支持中文和英文。
