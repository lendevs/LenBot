# 记忆与学习

LenBot 的记忆是保存在本地的 Markdown 文件，按群分开存放。学习指从群聊中积累说法、黑话、表情和回复效果，供 Bot 之后参考。两者都在群内空闲时由同一个整理回合完成。

## 记忆

### 存放位置

记忆保存在实例目录中，每个群一个目录，人物画像存放在 `people/<完整账号>/`。群友资料、群内事件和群画像由所有角色共用；Bot 自身的发言和承诺按角色分开，见[给群换角色](./personas#给群换角色)。

### 召回

每一轮开始时，LenBot 先读取最近几位发言人的画像，再用最近的对话检索相关记忆，结果作为本轮的参考材料。回想中 Bot 答应过的事和还没回答的问题也用来检索，最近对话没有再提到的事项也能找回相关记忆。模型也可以在回合中主动搜索和读取记忆。

- 默认使用全文检索，不需要额外服务。
- 配置向量模型后使用向量与全文混合检索，见[模型与用量](./models#向量检索)。
- 向量配置与已有索引不一致，或向量接口请求失败时，自动改用全文检索，错误写入运行日志。

### 查看和修改

在**群聊 → 记忆**中可以浏览、搜索、新建、修改和删除记忆。

![群聊 → 记忆 → 浏览：左侧是本群记忆的目录，右侧是打开的记忆文件和编辑、修改历史、删除按钮](/screenshots/memory.png)

- **删除**：保留修改历史。
- **遗忘**：清除这份记忆的正文、索引、旧版本和摘要。遗忘时还可以选择部分原话，之后不再从中学习。

### 换用插件提供记忆

提供记忆入口的插件可以接管一个群的长期记忆。在**群聊 → 设置 → 插件**中先打开这个插件，再在**长期记忆**里选择它；**压缩回想**也可以交给提供压缩入口的插件。保存后，这个群在当前回合结束时切换。

- 插件负责这个群的自动召回、`memory` 工具和后台整理，数据存在插件自己的目录里。
- 原生记忆文件原样保留，插件可以只读访问它们，用来导入。
- 切回原生记忆后，原生整理从切回时开始，插件接管期间的消息不补。
- 卸载插件后，用它的群回到原生记忆和原生回想。
- **群聊 → 记忆**页显示当前的记忆实现、插件处理到的位置和最近一次错误。
- 试聊使用一份空白的原生记忆，不加载插件，试聊标题旁显示这个群用的记忆插件。
- 插件写回想失败时，当前回合结束，错误显示在插件和回合记录中，已有回想和历史保留。修正插件后可再次压缩。

仓库里的 `examples/plugins/notebook` 是一个示例记忆插件，安装和配置见它的 README。

## 学习

在**群聊 → 学习**中开启后，LenBot 学习以下内容：

| 类型 | 内容 | 默认 |
|---|---|---|
| 说法 | 群友在什么情境下怎么说。新学到的说法进入待审核，采用后才会被 Bot 参考 | 开启 |
| 黑话 | 群内特有的词和它的词义。词义可以人工固定或禁用 | 关闭 |
| 表情 | 群友发送的表情图片和描述 | 关闭 |
| 回复效果 | Bot 发言后群友的反应，用来判断哪些回复效果好 | 关闭 |

学到的条目可以在学习页查看、修改和禁用。说法可以直接加入角色的样例。

推断黑话时，聊天模型同时比较本群用法和通常含义。沿用普通词义或常见比喻的候选归入已拒绝，群内特定用法留待审核；语境不足的候选保留较低信心，等待后续证据。已采用的词在出现得更多后继续推断，学习页显示最新推断，聊天时仍使用人工确认的含义。

## 整理回合

开启记忆整理（**群聊 → 记忆 → 设置 → 后台自动整理**）或学习后，LenBot 在群内空闲时运行整理回合：

- 由聊天模型在同一个聊天会话中完成。请求内容与聊天请求的前缀一致，可以命中服务商的缓存，减少重复计费。
- 一次整理同时完成记忆写入和学习，用量在**模型 → 用量与上限**中单独列为**整理记忆和学习**。
- 触发条件：群内安静超过设定时间且积累了足够的新消息，或距离上次整理超过最长等待时间。会话压缩前也会强制整理一次。各项阈值在记忆设置和学习设置中修改。
- 角色的工具许可需要包含 `memory`，否则不能写入记忆。

整理回合将原生记忆里的群友资料分为身份与称呼、关系、稳定事实、相处偏好与雷点、近期情况和不确定，每条带日期和消息来源。玩笑、自嘲和临时状态会保留当时的语境。过时的近期情况在后续整理时合并或清除；已有资料在下次整理到这个人时采用新的分节。

聊天召回会优先带上当前发言人的相处偏好，例如希望怎样称呼、是否希望被提醒进度，再结合近期情况和其他记忆理解本轮对话。记忆插件使用各自的整理和召回方式。

整理失败时，这一批的结果都不保存，处理进度不前进。LenBot 在 60 秒后自动重试同一批消息，连续失败 3 次后停止重试，等待在**群聊 → 记忆 → 后台整理**中点击**重新整理此批**。开启后只整理之后的新消息。

## 目录摘要

开启**为每个目录生成摘要，根目录摘要作为本群画像**后，LenBot 为每个记忆目录生成摘要，根目录的摘要作为本群画像。摘要由**记忆摘要**用途的模型编写，未单独配置时使用聊天模型。

## 重建索引

以下情况需要重建索引：

- 手动修改了记忆文件
- 更换了向量服务的地址、模型或维数（只修改服务商名称不需要）

在**群聊 → 记忆 → 索引**中点击**重建索引**，使用当前运行的向量配置重建。更换模型后，先按顶栏提示重启，再重建。重建期间记忆编辑和整理排队等待，聊天时的查询照常进行。全部向量生成成功后才替换索引。

也可以停止 LenBot 后在实例目录中执行：

```sh
uv run --no-sync python -m len_bot.next.maintenance.memory_reindex
```

正文和修改历史保留，目录摘要清除，之后整理时按新正文重新生成。

学习中的说法使用单独的向量配置。更换后，在该群学习页点击**重建索引**；重建前不按情境挑选说法。离线时执行 `uv run --no-sync python -m len_bot.next.maintenance.reindex_expressions`。
