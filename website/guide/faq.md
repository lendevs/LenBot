# 常见问题

## 首次配置的链接打不开

链接以 `127.0.0.1` 开头，是本机地址，只能在运行 LenBot 的机器上打开。LenBot 安装在远程服务器上时，先把终端中显示的端口转发到自己的电脑，再在本机浏览器中打开同一个链接。

```sh
ssh -L 52811:127.0.0.1:52811 你的服务器
```

## 测试连接时读取不到 Bot 账号

请按顺序检查以下几项。

1. OneBot 一侧的 QQ 已经登录，WebSocket 已经开启。
2. 使用正向连接时，地址填写的是 OneBot 的 WebSocket 服务端地址，以 `ws://` 开头。OneBot 运行在容器中时，需要把端口发布到宿主机。
3. 使用反向连接时，OneBot 使用 Universal 模式，地址和端口与 LenBot 的监听设置一致。
4. 两侧的访问令牌相同。

按钮下方会显示具体的错误信息，可以据此排查。连接方式的详细说明见[接入 QQ](./onebot)。

## 向导保存后没有跳转到面板

页面停在**配置已保存**，说明面板在半分钟内没有启动。请查看终端输出，常见原因是面板端口已被其他程序占用。

此时配置已经保存，问题解决后重新启动 LenBot 即可，无需重新配置。如果要更换端口，请先停止 LenBot，再修改 `lenbot.config.json` 中的 `panel.port`。

## Bot 在群里不说话

1. 在总览查看 QQ 是否在线，以及这个群的聊天开关是否打开。
2. 顶栏显示**模拟发送**时，回复只显示在面板中，不发送到 QQ。请在**总览**的状态卡上切换为**发送到 QQ**。
3. 新添加的群默认只回应 @ Bot 或回复 Bot 的消息。需要 Bot 主动参与时，在**群聊 → 设置 → 参与方式**中把**发言时机**改为**同时参与群内讨论**，再调整活跃度和关键词。
4. 设置了安静时段时，Bot 在这段时间内不主动发言。
5. 在**模型 → 用量与上限**中查看今天的 token 用量是否已达到上限。
6. 在**群聊 → 现场**展开对应的回合查看报错，或在**系统 → 日志**中筛选**仅错误**。

## 模型调用报错

报错开头说明处理方向，各类报错的含义和对应设置见[模型调用失败](./models#模型调用失败)。总览把同一服务商、同一用途的同类失败合并成一条，点开后显示最近一次失败的原始响应和 request id。首次配置时，可以在模型步骤用测试模型先确认连接、模型名和工具调用。

## 读取网页或获取图片总是失败

如果错误信息中有 `私有或保留地址`，通常是因为代理软件开启了 fake-ip 模式，见[联网与工具](./web#代理软件的-fake-ip-模式)。

## 启动时提示实例锁被占用

同一个实例在同一时间只能运行一个 LenBot 或一条维护命令，请先停止另一个。在终端中按 Ctrl-Z 挂起的进程仍然占用锁，请用 `fg` 切回该进程后按 Ctrl-C。

进程退出时自动释放锁。不要手动删除锁文件，否则可能有两个进程同时写入数据。

## 启动时提示格式变更不提供升级步骤

LenBot 发布前，配置和数据库的格式变更不提供升级步骤，更早版本写入的实例不能直接启动。请使用新的实例目录重新配置，旧目录可保留作备份。

## 登录面板时一直提示尝试过于频繁

同一 IP 在 15 分钟内输错 5 次密码后，该 IP 的登录暂时被拒绝，密码正确也一样，15 分钟后恢复。

反向代理和 LenBot 在同一台机器上时（Docker 部署也一样），LenBot 按代理转发的访问者 IP 计数。代理在另一台机器上时，要把代理的地址填进根配置的 `panel.trusted_proxies`，否则所有人都按代理的 IP 计数，一个人连续输错密码，其他人也会暂时无法登录。

## 是否支持其他聊天平台

目前只支持 QQ，通过 OneBot v11 接入。

## 能否用语音回复

不能。LenBot 可以把群内语音转写为文字，但只用文字回复。

## 如何查看 token 用量

**模型 → 用量与上限**中显示今天和本月的 token 用量，按模型和按群与用途分别列出，数字来自模型服务的报告。
