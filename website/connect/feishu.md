# 接入飞书

LenBot 以飞书企业自建应用的机器人身份接入，通过长连接接收事件，不需要公网地址。一个实例接一个应用，可以和 QQ、Telegram 同时运行。国际版 Lark 同样支持。

## 创建应用

在[飞书开放平台](https://open.feishu.cn/app)（Lark 为 [open.larksuite.com](https://open.larksuite.com/app)）创建**企业自建应用**：

1. **添加应用能力**：开启**机器人**。
2. **权限管理**：开通发送消息、读取单聊和群组消息、获取群组信息、获取群成员、上传图片和文件、读取消息中的资源文件等消息与群组权限。群里默认只收到 `@机器人` 的消息；要让 Bot 看到群里的全部发言，需要开通**获取群组中所有消息**，这是敏感权限，需要企业管理员审批。
3. **事件与回调**：订阅方式选择**使用长连接接收事件**，添加事件 `im.message.receive_v1`（接收消息）、`im.message.recalled_v1`（消息撤回）、`im.chat.member.user.added_v1`（用户进群）、`im.chat.member.user.deleted_v1`（用户出群）。
4. 创建版本并发布，管理员审核通过后生效。
5. 在要接入的群的**设置 → 群机器人**中添加这个机器人。

**凭证与基础信息**页的 **App ID** 和 **App Secret** 在下一步使用。

## 在面板中接入

**首次配置**：向导第一步**接入平台**选**飞书**，填写 **App ID**、**App Secret**，**版本**选择飞书或 Lark。点击**测试连接**，LenBot 读取机器人的 open_id 和它所在的群，显示 `已连接：应用名` 后进入下一步，第一个群可以从群列表中选择。主人填写飞书 open_id（`ou_` 开头）。

**已有实例**：在**系统 → 设置 → 连接**打开**飞书**卡片的开关，填写 App ID 和 App Secret，点击**测试连接**读取机器人账号，保存后重启生效。之后在**群聊**页接入新群时，机器人所在的群会出现在已加入的群列表中。

账号和场景都带 `feishu:` 前缀，例如群 `feishu:group:oc_xxx`、成员 `feishu:ou_xxx`。open_id 按应用区分，换一个应用后同一个人的账号会变，主人和各群名单需要重新填写。

## 能做什么

| 能力 | 飞书 |
|---|---|
| 收发文字、`@` 成员、回复指定消息 | 支持，富文本消息拆成文字、图片和提及 |
| 看图、收藏表情 | 支持，经消息资源接口下载 |
| 语音转写 | 支持，语音以 OGG Opus 原样交给语音识别服务 |
| 发送任务交付文件 | 支持，先上传再发送 |
| 群友发的文件交给后台任务 | 支持，聊天模型委托任务时按消息选取文件 |
| 撤回、入群、退群通知 | 支持 |
| 全员提醒 | 支持，需要群设置允许 `@所有人` |
| 群文件、成员资料查询、合并转发、表情回应 | 只在 QQ 提供 |

成员的显示名来自群成员列表和消息里的提及，没有获取群成员权限时以 open_id 显示。

语音转写使用**模型**页配置的语音识别服务，服务需要接受 OGG Opus 格式；QQ 的语音由协议端转成 WAV，不受影响。

## 插件

插件在飞书群里照常工作。没有获取群组中所有消息的权限时，命令要写成 `@机器人 /命令`。插件开发见[多平台](../develop/plugin-platforms)。
