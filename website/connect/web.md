# 联网与工具

聊天模型在回合中可按需调用内置工具与外部 MCP（Model Context Protocol，模型上下文协议）服务核实信息。本页说明网页搜索与正文读取、内置工具清单、MCP 服务配置，以及本机代理开启 `fake-ip` 时的网络设置。

## 搜索网页与读取网页

在**能力 → 网页**（或首次配置向导第 4 步）中分别选择搜索服务和网页读取方式。需要密钥的服务在**模型 → 服务商**中管理连接；搜索与读取选用同一家服务时可共用同一条连接。

| 搜索服务 | 密钥要求 |
|---|---|
| Yahoo、Bing RSS | 无需密钥 |
| DeepSeek | 聊天服务商为 `api.deepseek.com` 时可直接复用聊天连接，否则单独配置 DeepSeek 连接 |
| Tavily、Brave Search、博查 | 在服务商中配置对应协议的连接与 API Key |

| 读取方式 | 密钥要求与说明 |
|---|---|
| 本机直接读取（`local`） | 默认方式，无需密钥，由 LenBot 直接请求网页并提取正文 |
| DeepSeek | 复用 DeepSeek 搜索或官方聊天连接 |
| Tavily | 与 Tavily 搜索共用同一连接 |
| Jina Reader | 在服务商中配置 Jina Reader 连接与 API Key |

搜索可配置**每次最多结果数**（默认 `5`，上限 `20`）与**超时**秒数；关闭**允许搜索网页**或**允许读取网页**开关即卸载对应工具（在 `lenbot.config.json` 中对应 `"web_search": null` 或 `"web_read": null`）。网页服务若复用了已加载的服务商连接，修改参数保存后立即生效；新建或修改了服务商连接时重启后生效。

## 内置聊天工具一览

除基础发言工具 `say`、表情工具 `react` 和等待工具 `wait` 常驻外，其余低频工具默认收起，由聊天模型按需通过 `tool_search` 检索装载，节省常驻上下文开销。角色可调用的工具范围由角色包的 `tools` 字段（**角色 → 工具与技能**）控制，见[写角色包](../develop/personas#persona-yaml)。

| 工具名 | 面板名称 | 作用 |
|---|---|---|
| `say` | 发言 | 发送群聊或私聊文字消息，可引用原消息、`@` 群友或附带一张表情 |
| `react` | 表情回应 | 按情绪或标签检索、预览并单独发送角色表情或本群收集的表情 |
| `message_reaction` | 贴表情 | 为指定 QQ 群消息贴一个表情回应 |
| `wait` | 等待 | 对方尚未说完时暂停数秒，读取新到达的消息后继续本轮 |
| `recall_chat` | 查询聊天记录 | 按关键词（多个关键词需同时命中）、发言人或时间窗口检索本群历史消息，默认最新优先，并可读取前后文 |
| `memory` | 记忆 | 搜索、浏览、读取或更新长期记忆，见[记忆与学习](../use/memory) |
| `knowledge` | 查资料 | 检索角色设定资料与本群资料文件，返回原文片段与定位，见[资料检索](../use/reference) |
| `look` | 看图 | 查看历史消息或当前消息中的图片内容 |
| `open_forward` | 读取合并转发 | 展开 QQ 合并转发消息内的对话记录 |
| `member_info` | 查群成员 | 查询 QQ 群成员名片、昵称和群头衔 |
| `transcribe` | 转写语音 | 调用语音转写模型识别指定语音消息 |
| `attention` | 持续关注 | 登记短期内需要继续留意的群内事项，命中后续消息时自动唤醒跟进 |
| `schedule`、`schedule_list`、`schedule_cancel` | 创建／查看／取消提醒 | 为群友或 Bot 自身管理一次性与周期性定时提醒 |
| `delegate`、`task`、`send_file` | 委托任务／任务／发送文件 | 发起和管理 Docker 后台任务并将交付文件发往群内，见[后台任务](../use/tasks) |
| `scene_control` | 临时安静 | 应有权限成员的要求让本群进入临时安静状态 |
| `host_manage` | 管理设置 | 供主人或全局管理员在群内通过自然语言查看和修改宿主配置 |
| `tool_search` | 查找工具 | 按关键词检索并装载当前场景可用的按需工具与 MCP／插件工具 |

## MCP 服务

在**能力 → MCP 服务**中点击**添加服务**，可将外部 MCP 工具接入指定群聊。连接参数修改后需重启 LenBot 生效，运行期间可在详情页手动点击**重新连接**或**断开**。

支持两种传输方式：

- **本机程序（`stdio`）**：由 LenBot 启动本机子进程，填写**启动命令**、**命令参数**（每行一个）、可选的**工作目录**和**环境变量**。
- **网络地址（`http`）**：连接远程 Streamable HTTP／SSE 端点，填写 `http://` 或 `https://` **服务地址**，鉴权凭据填入**请求头**。

每个勾选**启动时连接**的 MCP 服务至少需分配一个**可用的群**，并可分别设定**单次调用超时**（默认 30 秒）和**单次结果大小上限**（默认 1 MiB）。服务名称以小写英文字母开头，仅含小写字母、数字和单下划线，最长 24 位。

## 代理软件的 fake-ip 模式

本机运行 Clash、Surge、Mihomo 等开启了 `fake-ip`（虚拟 IP 映射）模式的透明代理时，系统 DNS 会把公网域名统一解析到 `198.18.0.0/15` 等保留地址段。LenBot 在本机读取网页、拉取公网图片以及转发后台任务联网请求时，默认拦截所有私有与保留 IP 地址以防范服务端请求伪造（SSRF），此时报错中会出现 `私有或保留地址`。

处理方式：打开**能力 → 网页**，在底部**代理的 fake-ip 网段**中填入代理实际使用的虚拟网段并保存重启（对应根配置 `network` 节）：

```json
"network": {
  "fake_ip_networks": ["198.18.0.0/15"],
  "public_dns_url": "https://dns.google/resolve"
}
```

配置后，当按域名发起的连接解析结果落入 `fake_ip_networks` 时，宿主会通过 `public_dns_url`（支持标准 DNS over HTTPS JSON 查询参数 `name` 与 `type`）核验该域名的真实公网 A／AAAA 记录：

- 真实记录确认为公网地址后，放行连接。
- DNS 查询失败，或真实记录指向局域网／回环地址时，立即拒绝连接。
- URL 中直接写死保留 IP 字面量的请求始终拒绝；`fake_ip_networks` 亦不允许填写 `10.0.0.0/8`、`192.168.0.0/16` 等真实内网网段或公网网段。
