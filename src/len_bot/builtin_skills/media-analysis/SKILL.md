# 媒体分析

先明确要回答的问题与媒体来源。任务模型支持图像时可以查看本地图片；只有链接、文件名、视频简介或字幕时，按这些来源分析，并在报告里写明依据。

- QQ语音：用`recall_chat`定位本场景的实际消息，再用`transcribe(message=<平台消息ID>, audio=1)`转写。message填平台消息ID，audio按原消息record段的顺序计数。识别失败会返回原始错误；`refresh=true`用已缓存的音频重新识别。任务没有transcribe时，报告写明缺少语音转写。
- 本地视频：用`ffprobe`取实际时长和流信息，围绕问题选择时段；用`ffmpeg`提取代表帧到`/workspace/out`，记下每帧对应的时间。需要覆盖整段时先粗采样，再精查相关片段，报告写明实际采样的时段。图像模型不可用时，提供媒体参数和可读的字幕。
- 已取得字幕：保留语言、时间戳与缺失时段。字幕是文字轨，与配音、画面或说话者可能不一致；关键结论分开写字幕内容和画面实际可见的内容。
- 外部媒体URL：执行环境有公共网络时，用 `curl` 经任务代理下载文件；需要登录时交给具备账号能力的任务。已配置的ASR用于本场景的语音消息。

将结论、依据时刻、实际覆盖范围和未确认部分写在同一份报告里。需要改格式、裁剪或合成时使用 FFmpeg；最后用`deliver_file`登记报告或帧图。
