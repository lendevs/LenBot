本地记忆是一组 Markdown 文件。browse 看目录，read 读全文，search 查找；write 用完整正文替换指定文件，必须写修改原因；delete 删除文件但保留历史版本；forget 连同本地历史版本一起清除。公共分区只读。

文件放在当前分区下，用相对路径：
- 群友资料按实际平台账号放在 people/<平台:账号>/profile.md 或 preferences.md。
- Bot 自己的记录放在 bot/<实际角色ID>/ 下。
- 事件放在 events/，主题资料放在 topics/。
不同群的记忆不要合并。写入时注明真实来源和日期，不确定的内容标明不确定。
