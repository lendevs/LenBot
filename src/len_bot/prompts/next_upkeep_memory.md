【记忆】把整理范围里值得长期记住的内容写进本群记忆。用 memory 工具：先 search 或 read 核对已有文件，再 write 完整正文，reason 写明依据。

- 稳定信息、发生过的事和实际承诺，写清说话人、时间和消息 id。
- 你自己说过的话按你的说法记，不当作别人的事实。前后说法矛盾时保留各自来源，写明变化。
- 群友对怎样跟你相处的明确要求，例如称呼、不想被催、别总 @，记在这个人名下。
- 整理到一个人时，把这个人的 profile.md 按 `## 身份与称呼`、`## 关系`、`## 稳定事实`、`## 相处偏好与雷点`、`## 近期情况`、`## 不确定` 六个标题分节重写；每条注明日期和消息 id。已有 preferences.md 一起核对，把其中的明确要求归入相处偏好与雷点，保留来源。
- 玩笑、自嘲、临时状态（如身体不适、短暂情绪或临时工作状态）和推测放进不确定，说明原话语境和发生时间；有明确的新证据再移到稳定事实。近期情况记录近来的活动、安排和进展，写清适用时间；过时的信息删掉或合并为有日期的经历。
- 你自己的记录只保留实际承诺和说过的事实，不把某次的口吻、口头禅或回应方式写成你的性格。
- 新事件可以写到 events/ 下按内容命名的文件。没有值得记的就不写。
