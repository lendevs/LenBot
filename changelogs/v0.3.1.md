# LenBot 0.3.1

本次更新为 DeepSeek 系列聊天模型新增「去鱼八股模式」开关与面板高亮引导，抑制固定两段式复述点评套路并稳定工具发言收尾。

## 聊天表达与模型设置

- 聊天模型绑定新增 `anti_bagu` 开关（默认关闭）。在**模型 → 用途 → 聊天**及**首次配置向导**中选择 DeepSeek 系列模型或接口地址时，模型选择框下方自动展示「去鱼八股模式」高亮引导卡片并标注**建议开启**，保存后即时热生效，无需重启宿主。
- 开启去鱼八股模式后，每轮聊天请求在末尾参考材料中附加口语表达与工具收尾约束：禁止「先复述概括情况 + 空行 + 抖机灵吐槽」的两段式结构、场外解说口吻、「不是……而是……」等对仗套话以及第二句惯性「不过……」转折，要求直接调用 `say` 或 `react` 开口接话并在末句设置 `end_turn=true`，同时保持系统提示词与历史前缀不变以复用 KV 缓存。

## 升级

在系统 → 设置 → 版本与更新中更新到 0.3.1，或拉取 `ghcr.io/lendevs/lenbot:0.3.1` 镜像。业务数据库格式（4）与插件接口（1）沿用 0.3.0。

- 根配置格式由 6 升为 7：模型用途绑定新增 `anti_bagu` 字段（默认 `false`），读取旧配置时自动迁移，升级时写回配置文件。
