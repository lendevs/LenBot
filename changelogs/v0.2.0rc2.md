# LenBot 0.2.0rc2

LenBot 首个公开版本的第二个候选版。相对 0.2.0rc1 增加 Telegram 与飞书接入和插件市场的社区目录，并修正面板走查中发现的问题。

## 下载

| 内容 | 文件或镜像 |
|---|---|
| Linux x64 部署包 | `lenbot-0.2.0rc2-linux-x64.tar.gz` |
| Linux arm64 部署包 | `lenbot-0.2.0rc2-linux-arm64.tar.gz` |
| Windows x64 部署包 | `lenbot-0.2.0rc2-windows-x64.zip` |
| 宿主镜像（amd64、arm64） | `ghcr.io/lendevs/lenbot:0.2.0rc2` |
| 后台任务镜像 | `ghcr.io/lendevs/lenbot-worker:0.2.0rc2` |
| 更新器镜像 | `ghcr.io/lendevs/lenbot-updater:0.2.0rc2` |
| 程序 wheel 与源码包 | `len_bot-0.2.0rc2-py3-none-any.whl`、`len_bot-0.2.0rc2.tar.gz` |

三个镜像在 Docker Hub 上也有同名副本。每个附件的大小和 SHA-256 记录在 `release-manifest.json` 中。

## 从 0.2.0rc1 升级

在面板**系统 → 设置 → 版本与更新**选择 0.2.0rc2。更新前自动快照实例，升级时把根配置迁移到格式 2（`delivery` 的 `onebot` 改为 `live`），迁移和检查失败时回到 rc1。不用更新器的 Docker 部署，用同一个数据卷启动 rc2 镜像即可，启动时先快照再迁移。

## 新增

- **Telegram**：直接调用 Bot API，长轮询收消息，不需要公网地址和协议端；需要时可配 HTTP 代理和自建 Bot API 地址。收发文字、提及、回复、图片、文件和语音；超过 4096 字（带图 1024 字）的文字在换行处拆成多条。见[接入 Telegram](https://lendevs.github.io/LenBot/connect/telegram)。
- **飞书**：以企业自建应用的机器人接入，长连接接收事件，飞书与 Lark 都支持。收发文字、富文本、提及、回复、图片、文件和语音，撤回与进退群通知。见[接入飞书](https://lendevs.github.io/LenBot/connect/feishu)。
- **多个平台同时运行**：QQ、Telegram、飞书可以接在同一个实例上，各平台独立重连；每个群用所属平台的 Bot 账号，场景 ID 带平台前缀。看图、表情收集、语音转写和委托任务时选取群友发的文件（`chat_files`）在三个平台都可用；群文件、成员资料、合并转发和表情回应只在 QQ 提供。
- **面板**：**系统 → 设置 → 连接**按平台分卡片，各自启用、填写凭据和测试连接；首次配置向导第二步选择 QQ、Telegram、飞书或暂不接入；群聊页的已加入群列表覆盖所有已连接的平台。
- **插件市场**：发现插件页合并三个目录来源：随附的官方目录、[社区插件目录](https://github.com/lendevs/lenbot-plugin-index)和可选的自定义目录地址，同名插件以排在前面的来源为准。可以按来源筛选，卡片和详情标出插件来自哪个目录；某个来源读不到时，其余来源照常列出。A-SOUL 日程与动态插件移到社区目录。
- **官方插件**：随附目录更新到群聊总结与群工作 1.3.4（日报卡片发送失败时记录错误并回复原因）、GSUID Core 桥接 1.2.1（只在 QQ 群启用）、哔哩哔哩 1.2.0（移除点赞、收藏和账号写入工具）。哔哩哔哩从 1.1.x 更新前，先从插件配置中删除 `bili_jct`、`daily_like_limit`、`daily_favorite_limit`、`allowed_collection_ids` 和 `quota_timezone`。
- **插件接口**：命令匹配按群所属平台的 Bot 判断开头提及；新增 `Invocation.platform`、`Invocation.bot_id`、`PluginContext.bot_for`、`PluginContext.platform` 和读取平台文件的 `fetch_media`；清单可用 `chat_platforms` 声明支持的平台。见[多平台](https://lendevs.github.io/LenBot/develop/plugin-platforms)。

## 修正

- 面板：顶栏路径不再重复显示同名分组，群聊页显示群名；总览的 token 输入、输出拆分移入卡片；回合摘要写明总耗时；表单分节没有字段时只显示标题行；发送方式为真实发送而总览临时切到模拟发送时，系统页的连接卡片显示标记。
- 服务商测试默认填入使用该服务商的聊天用途模型。
- 发现插件页的更新按钮只对 Git 安装的插件显示；ZIP 安装的插件导入新的 ZIP 更新。
- 插件应用、取消和回滚后，面板不再因为 `plugins.disabled_rules` 误报需要重启。
- Linux 部署包自带时区数据，在没有安装系统时区库的环境（例如最小化的容器镜像）中也能完成首次配置。

## 候选版说明

- 根配置格式为 `2`，数据格式与插件接口编号仍为 `1`。
- 部署包没有代码签名，Windows 首次运行的处理方法见部署包页。
