# LenBot 0.2.6

本次更新修复聊天查询阻塞消息写入、手动整理请求丢失和回合结束状态显示滞后的问题，并完善角色热更新与停机升级检查。

## 聊天与整理

- 聊天上下文和后台整理的历史查询改用只读连接，长查询期间可以继续写入新消息。
- 插件在工作线程读取聊天记录时使用独立的读取快照。
- 规划读库或准备会话历史期间收到的整理请求保留给下一轮，已有请求时再次触发整理也能处理新消息。
- 回合状态写入数据库后再发出结束事件，面板收到事件时可以读取已完成的回合状态。

## 角色与升级

- 多个群共用同一角色时，角色内容热更新只加载一次资源快照，再应用到各群。
- 停机升级时补建当前业务库声明中缺失的索引，已使用当前数据库格式的实例也会检查。

## 项目展示

- 更新 README 头图、决策回合说明与文档站聊天演示，展示回合内追加最新群聊消息的流程。

## 升级

在系统 → 设置 → 版本与更新中更新到 0.2.6。配置格式、数据库结构和插件接口沿用 0.2.5，升级时会补齐缺失索引。
