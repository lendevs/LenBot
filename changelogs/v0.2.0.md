# LenBot 0.2.0

LenBot 首个公开版本。此前的开发版本都叫 0.1.0，没有公开发行；0.2.0rc1 和 0.2.0rc2 是这一版的候选版。

## 下载

| 内容 | 文件或镜像 |
|---|---|
| Linux x64 部署包 | `lenbot-0.2.0-linux-x64.tar.gz` |
| Linux arm64 部署包 | `lenbot-0.2.0-linux-arm64.tar.gz` |
| Windows x64 部署包 | `lenbot-0.2.0-windows-x64.zip` |
| 宿主镜像（amd64、arm64） | `ghcr.io/lendevs/lenbot:0.2.0` |
| 后台任务镜像 | `ghcr.io/lendevs/lenbot-worker:0.2.0` |
| 更新器镜像 | `ghcr.io/lendevs/lenbot-updater:0.2.0` |
| 程序 wheel 与源码包 | `len_bot-0.2.0-py3-none-any.whl`、`len_bot-0.2.0.tar.gz` |

三个镜像在 Docker Hub 上也有同名副本；两个仓库的镜像都带有 `latest` 标签。每个附件的大小和 SHA-256 记录在 `release-manifest.json` 中。

## 部署方式

- **部署包**：内含 Python 3.13、锁定的依赖、时区数据、uv 和网页面板，解压后运行 `run` 或 `run.cmd` 即可启动，本机不需要另装 Python。Linux 包适用于 glibc 2.28 及以上的发行版，并带有后台任务的本机沙箱运行时（Node、Pi 与任务 Python 库）。面板的**系统 → 设置 → 版本与更新**负责更新、快照和恢复。见[部署包](https://lendevs.github.io/LenBot/start/package)。
- **Docker**：一条 `docker run` 加一个 `lenbot-data` 数据卷。用同一个卷启动新版本镜像时，先把实例快照到 `/data/backups/`，再迁移数据。需要在面板中切换版本和自动回滚时，可以改用更新器部署。见 [Docker 部署](https://lendevs.github.io/LenBot/start/docker)。macOS 使用 Docker 部署。
- **源码**：uv 与 Node.js 22，跟随 `master` 分支。见[源码运行](https://lendevs.github.io/LenBot/start/source)。

首次启动后，按终端或容器日志里的一次性链接完成五步向导：管理员账号、接入平台（QQ、Telegram、飞书或暂不接入）、主人与时区、聊天模型、角色和第一个群。

## 包含的功能

- **群聊决策**：Bot 接入 QQ（OneBot v11）、Telegram 和飞书，何时开口、回复谁、先查什么、何时跟进，由 ReAct Loop 决定。可以用表情、引用和提及，较长的对话压缩成回想。
- **多个平台同时运行**：QQ、Telegram、飞书可以接在同一个实例上，各平台独立重连，每个群用所属平台的 Bot 账号。Telegram 直接调用 Bot API 长轮询收消息，不需要公网地址和协议端；飞书以企业自建应用的机器人接入，飞书与 Lark 都支持。群文件、成员资料、合并转发和表情回应只在 QQ 提供。见[接入 Telegram](https://lendevs.github.io/LenBot/connect/telegram)、[接入飞书](https://lendevs.github.io/LenBot/connect/feishu)。
- **查证回答**：按需搜索网页、读取正文、查询聊天记录与长期记忆、检索角色和本群资料、识别图片、读取合并转发。
- **主动跟进**：为群友创建提醒、登记持续关注的事项，或把耗时工作交给后台任务。
- **后台任务**：编程助手 Pi 在隔离环境中执行长任务：Linux 部署包用本机沙箱（bubblewrap），Docker 部署与 Windows 部署包用 Docker 任务容器。任务默认不联网，可按域名放行或开放公网，产物登记后发到群里。
- **记忆与学习**：记忆以 Markdown 文件按群保存在本地，默认全文检索，可选向量检索；支持后台整理、修改历史和彻底遗忘。学习群内的说法、黑话和回复效果。
- **角色包**：设定、说话方式、底线、样例、资料和表情组成一个角色，可以导入导出，修改前可以用草稿试聊；群内用 `/角色` 切换。
- **插件**：Python 插件可添加命令、定时播报、模型工具或长期记忆实现，可以用 `wait_message` 等同一个人的下一条消息完成多轮对话，按群启用；清单可用 `chat_platforms` 声明支持的平台。支持 Git 和 ZIP 安装、权限声明、独立进程运行和单个插件重新加载，插件依赖装在实例目录下，按宿主版本分开。见[插件开发](https://lendevs.github.io/LenBot/develop/plugins)。
- **插件市场**：发现插件页合并随附的官方目录、[社区插件目录](https://github.com/lendevs/lenbot-plugin-index)和可选的自定义目录地址，可以按来源筛选。官方目录收录群聊总结与群工作、GSUID Core 桥接、哔哩哔哩三个插件，独立安装和更新。
- **管理面板**：总览、对话测试、群聊设置、角色、记忆、资料、插件、任务、模型用量与日志；**系统 → 设置 → 连接**按平台分卡片设置和测试连接。对话测试可以模拟一个群，以不同群友的身份发言并查看每个回合。

## 从候选版升级

在面板**系统 → 设置 → 版本与更新**选择 0.2.0。更新前自动快照实例，迁移和检查失败时回到原版本。从 0.2.0rc1 升级时根配置迁移到格式 2（`delivery` 的 `onebot` 改为 `live`）。不用更新器的 Docker 部署，用同一个数据卷启动 0.2.0 镜像即可，启动时先快照再迁移。

相对 0.2.0rc2 的修正：

- 面板的版本与更新页和更新器的更新与恢复页按 Markdown 显示发布说明，表格、标题和链接不再显示为原文。更新与恢复页随更新器发布，从 0.2.0 起的更新器生效。
- 对话测试在 @ 菜单中选择提及后，焦点回到输入框。

## 版本说明

- 根配置格式为 `2`，数据格式与插件接口编号为 `1`。之后跨版本的格式变化由升级流程迁移。
- Linux 本机沙箱启用任务后把无头 Chromium 下载到 `~/.cache/lenbot/`，试渲染成功后任务可以使用 `lenbot-render`；浏览器 `lenbot-browser` 只在 Docker 任务容器中提供。
- 部署包没有代码签名，Windows 首次运行的处理方法见部署包页。
