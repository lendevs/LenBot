# LenBot 0.3.0

本次更新全面重做网页面板与插件管理体验，将面板查询和历史检索移入独立只读连接池以消除大库卡顿，增强前缀缓存、长会话分批压缩与后台任务协同调度，并完善多帧动图与多平台收发细节。

## 网页面板与插件管理

- 统一全站视觉层级、设计令牌、深浅色对比度、390 px 窄屏布局、中英双语词条与键盘可达性，支持 `Ctrl/⌘ K` 全局命令面板直达各群、角色、插件与系统分栏。
- 插件市场支持独立安装进度、拖拽导入压缩包与已装卡片行内启停和重载；插件详情支持一步保存并应用候选版本、Schema 表单与脱敏 JSON 双模编辑、按群批量启停，以及命令、全文和正则单条规则开关。
- 角色工作台升级八大页签按字段合并保存、知识库与表情批量导入及内置试聊；群聊工作台升级保活页签、临时静默倒计时、现场时间线断层跳回最新、群记忆双模编辑与 Myers 行级历史对比、群资料检索测试、群学习批量审核、任务看板置顶提问与群设置分节导航。
- 模型中心新增月度用量趋势图与多端修改冲突增量合并；能力中心支持任务沙盒 MCP 开关与凭据校验；系统设置支持提示词默认对比、运行中 OneBot 反向连接实测与更新进程校验；优化首次配置向导参数联动与压缩区间校验。

## 存储性能与离线压缩

- 业务数据库启用独立只读连接池承接面板查询、历史检索与回想估算，避免慢查询阻塞主事件循环；两字短词历史搜索改为按游标分块扫描，不再受最近 5000 条消息截断限制；日志文件改为反向流式读取。
- 在线保留策略按游标清理过期请求快照并支持增量回收空闲页，保留期热修改即时生效；暂停或关闭的群聊入队插件通知直接标记已投递，不再积压历史事件。
- 新增停机离线回收命令 `python -m len_bot.next.maintenance.compact`，可在空间紧张的实例上先行清理非锚点历史请求快照并通过 `VACUUM INTO` 回收磁盘空间，支持 `--dry-run` 预估可回收体积与所需临时空间。

## 会话、缓存与记忆

- 补齐原生请求缓存断点与缓存亲和标识，末步工具收尾保持工具定义稳定以避免击穿前缀缓存；按块折叠较早的大体积只读工具输出，同轮尚未交给模型的工具结果不会被提前折叠或压缩。
- 待压缩历史超出上下文窗口时自动回退至更早完整边界分批消化，角色交接循环消化全量批次后原子提交；未发出的纯文本内部想法以中性格式投影，不再引发后续回合沉默传染。
- 记忆整理按文件基线原子校验提交，避免覆盖整理期间的人工编辑；自动召回过滤口头禅与高频虚词噪声，并修复 Windows 下中文及带冒号路径的本地记忆编解码。

## 后台任务与平台媒体

- 模型并发槽位升级为直接交互、普通聊天、后台任务与后台整理四级优先级调度，并在非交互槽位间轮转防饥饿。
- 后台任务流式模型请求按收到的数据分块自动续期超时，断流或超时时保留已上报的部分用量；新增无额外模型开销的任务看门狗，对同参循环、连续报错与静默空闲发送纠偏提示；任务处于待回答状态时支持请求人发言穿透唤醒，并在轮次状态与回想中保留活跃工单锚点。
- 多帧 GIF / WebP 动图提取关键帧拼成带时间轴的预览图供视觉模型识别，重媒体请求独立放宽超时并记录迟到回执；支持自定义表情短别名直调，优化超长群名片截断与 Windows 平台 `file://` 本地媒体路径解析。

## 升级

在系统 → 设置 → 版本与更新中更新到 0.3.0。根配置格式（6）和插件接口（1）沿用 0.2.8。

- 业务数据库格式由 3 升为 4，升级时为图片缓存补充帧数列（`image_cache.frames`），并建立场景消息、通知、插件调用、回合启动时间与未过期请求快照索引。
- 数据库较大时首次升级建索引耗时明显增加，10 GB 以上的库可能需要数分钟，期间实例保持停止。
- 升级前会自动创建快照，请确认磁盘剩余空间大于实例数据目录。升级后 0.2.8 无法打开格式 4 的业务数据库，回退需要使用升级前的快照。
