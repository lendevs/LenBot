# LenBot 0.4.0

本次更新升级群聊上下文投影、发送前因果仲裁、语义注意力脉冲与 DeepSeek 思考诊断体系，提升多人群聊的表达自然度、响应稳定性与前缀缓存命中率。

## Chat-Last 上下文投影与表达去回声

- 聊天请求改为 `[system, 历史对话, 轮次状态快照, 本轮新消息与工具步]` 三段投影，使群友本轮原话与工具结果紧贴生成末尾；历史段自动剥离旧话题新鲜度标签，协议层按显式历史边界在合并后的历史末块标记缓存断点。
- 已确认送达的 `say` 工具回执在模型上下文与压缩回想源中折叠为投递状态、分段数、平台消息 ID 与时间元数据，不再重复拼接发言正文；群友反应反馈移除冷场与无关台词的原句回灌，近期句式提醒排除未发出草稿并扩展结构性套话与空格分段问句检测；聊天提示词引导直接通过 `say` 或空参 `end_turn` 收尾，减少正文草稿双写。

## 非阻塞记忆召回与精准对话锚定

- 聊天主循环全程使用角色配置的主思考强度；轮首自动召回优先本地直读回复目标与近期发言人的 `profile.md` 及 `preferences.md`，按本轮活跃成员隔离个人档案偏好，并将记忆向量检索与群内说法向量检索置于共享截止窗口并发执行，远端向量等待移出场景锁，超时自动降级本地词面检索。
- 出站表达独立保存语义回复目标 `semantic_reply_to`（不影响平台可见引用框省略策略），删除全群广播焦点与多人轮次焦点，仅对语义回复对象或单人直通发起人开启短时续话窗口，并将精准续话优先级置于关键词点名之前。

## 逐段发送前因果仲裁、语义脉冲与面板诊断

- 分段发送每段提交平台前及贴表情前，在单次数据库事务内原子检查晚于本步上下文游标的因果竞争消息（直通新消息、目标对象续话、同问题被抢答，以及慢查询后的单次弱竞争重判），命中时保留已发出分段并将未发余段记为 `held`（`未发`），把新消息喂回当前轮重判且在末步预留保底重判步避免吞答；全角色在关闭局部收尾时常驻开放基础 `end_turn`，末步收尾同时开放 `say`、`react`、`message_reaction` 与 `end_turn`。
- 群聊参与新增 `Semantic Pulse`（支持 `off`、`shadow`、`active` 三档，默认 `off`）与自然语言持续关注条件 `watch`（兼容读取旧 `keywords`）：在执行锁外对模糊唤醒与挂念按采样间隔防抖筛选，直通唤醒零等待即时抢占在途采样。
- 模型连接测试新增真实思考链观测标记 `reasoning_observed`，在模型页与首次配置向导升级 DeepSeek 一键特调与无思考链警告；群聊现场时间线支持展示 `未发`（`Held`）工具状态，回放评测将成功贴表情计入社交回应并新增双写统计与离线盲评对比脚本。

## 升级

在系统 → 设置 → 版本与更新中更新到 0.4.0，或拉取 `ghcr.io/lendevs/lenbot:0.4.0` 镜像。插件接口（1）沿用 0.3.2。

- 根配置格式由 7 升为 8：群聊 `attention` 新增 `pulse` 配置（默认 `mode: "off"`，`sample_interval_seconds: 120.0`），读取旧配置时自动迁移，升级时写回配置文件。
- 业务数据库格式由 4 升为 5：`turns` 表新增可空整数列 `turn_floor_seq`，升级时自动建立快照并补齐该列。
