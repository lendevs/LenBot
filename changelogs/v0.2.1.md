# LenBot 0.2.1

本次更新完善插件的聊天配置、主人私聊和群聊接话节奏，并修复 0.2.0 部署后发现的问题。

## 聊天与配置

- 主人首次私聊时自动接入，沿用同一平台第一个群的角色。系统 → 设置 → 权限可调整主人私聊开关；其他账号通过群聊页手动接入私聊。
- Bot 仅靠对话继续连续发言、无人回复或提及时，默认接两轮后恢复常规参与判断。群聊 → 设置 → 参与方式中的没人接话时最多接几轮可调整上限，0 表示不限；直接回复、提及和点名会重新计数。
- 清除语音转写模型时，同步关闭所有场景的语音转写。
- 一轮学习整理中途关闭学习时，候选保留待审。

## 插件

- 插件接口 1 新增 `configure` 权限和 `ctx.update_config(changes)`，按插件清单校验并写回根配置，立即更新运行中的配置。并发修改不同字段时保留各次修改。
- 群关闭聊天后仍保留插件工具目录，恢复聊天后工具完整。
- 升级检查正确识别插件的 `disabled_rules` 配置。
- 哔哩哔哩 1.3.0：搜索视频和 UP 主，自动获取搜索设备 Cookie；主人可以发送 `/B站登录` 或让 Bot 发出扫码登录二维码，在聊天中添加或取消本群的开播、动态、视频和评论订阅。
- A-SOUL 1.4.0：主人可以在聊天中调整开播前提醒，继续使用特别关注工具管理单场高亮；由社区目录提供。
- 群聊总结 1.3.5：补充日报、增量整理、文字摘要和群工作的插件说明。

## 升级

在面板的系统 → 设置 → 版本与更新中升级至 0.2.1。根配置迁移到格式 3，插件接口与数据库格式保持为 1。使用更新器的实例在升级前自动建立快照。

先更新宿主，再在插件市场更新插件；哔哩哔哩 1.3.0 与 A-SOUL 1.4.0 需要 LenBot 0.2.1。角色使用明确的工具名单时，加入 `bilibili_login`、`bilibili_subscription` 或 `asoul_schedule_settings`，并保留 `tool_search`。角色允许全部工具时直接使用。
